현재 **시연 30을 단독으로** 진행합니다. 시연 28의 **299전이 종료 체크포인트**에서 출발해 양팔의 착의 깊이를 맞춘 뒤 목과 어깨를 덮고, 로컬 평가 **50점**을 목표로 합니다.

## 시연 30 계획

| 단계 | 조작과 확인 기준 |
|---|---|
| 시연 28의 마지막 장면에서 시작 | 종료 체크포인트의 출처와 해시를 확인합니다. 복원·정착 후 양쪽 손, 전완, 팔꿈치, 노란 밑단, 두 집게의 관계를 여러 시점에서 다시 봅니다. 새 회차는 0전이부터 기록합니다. |
| 양팔 착의 깊이 맞추기 | 왼손에 가까운 로봇이 왼쪽 노란 밑단의 바깥 끝을 잡습니다. 반대쪽 지지를 유지하면서 왼팔과 오른팔에 옷이 들어간 깊이를 비슷하게 맞춥니다. |
| 양쪽 끝으로 팔꿈치에서 어깨까지 전진 | 두 로봇이 각각 자기 쪽 밑단 끝을 잡고, 팔꿈치에서 어깨 방향으로 같은 구간에서 조금씩 전진합니다. 동작 뒤 양쪽 천이 함께 따라왔는지 확인합니다. |
| 중앙 양옆으로 목 착의 | 천이 어깨에 가까워지면 기존 지지를 한쪽씩 유지하면서 노란 밑단 중앙에서 좌우로 조금 떨어진 두 지점의 윗부분을 각각 다시 잡습니다. 두 집게로 함께 끌어올리며 실제 목둘레를 정수리 위로 넘긴 뒤 머리가 목둘레 밖으로 나왔는지 확인합니다. |
| 양쪽 끝으로 돌아가 어깨 착의 | 목둘레를 유지하면서 두 로봇이 각각 자기 쪽 밑단 끝을 다시 잡고 양쪽 어깨에 천을 보냅니다. 두 소매 밖의 손, 양쪽 어깨와 옷의 앞면을 여러 카메라에서 확인하고 원점수와 착의 성공 판정을 기록합니다. |

**시연 30부터 적용하는 기본 동작.** 손목에 옷이 걸쳐 있고 파지가 안정적이며 이동 경로가 보이면 행동당 **12–20전이**로 팔꿈치와 어깨 쪽으로 빠르게 진행합니다. 새 파지를 시험하거나 접촉·장력·가림·여유가 불확실할 때는 짧게 움직여 확인하고, 조건이 다시 보이면 12–20전이로 돌아갑니다.

후속 시연에서는 양쪽 손목이나 양쪽 팔꿈치까지 옷이 걸린 상태를 확인한 장면을 출발 후보로 삼습니다. 원본 시연 25의 1,200전이와 시연 26의 2,346전이 및 이후 슬롯은 비교 자료로 보존합니다. 출발점부터 목과 어깨까지 걸린 새 전이와 실제 시간을 남깁니다. [체크포인트와 재파지 분석](docs/active/20261126-demo25-27-analysis.ko.md)

## 현재 진행

- **시연 30 · 진행 중.** 시연 28의 299전이 종료 슬롯에서 새로 복원합니다. 복원·정착 뒤를 0전이로 세며, 새 전이 200개마다와 종료 직전에 저장합니다.
- **시연 29 · 종료.** 같은 시연 28 슬롯에서 시작했고, 336전이에서 종료 체크포인트를 저장했습니다.
- **시연 28 · 종료.** 시연 25의 1,200전이 체크포인트를 복원한 뒤 새 행동 299전이를 기록했고, 종료 슬롯을 검증해 보존했습니다.
- **시연 27 · 종료.** 시연 25의 행동을 2,346전이까지 재생한 뒤 양팔 우선 접근을 시작했습니다. 2,389전이에서 종료 체크포인트를 저장했고, 로컬 평가에서 5/50점을 기록했습니다.

시연 28의 영상과 착의 결과, 후속 시연에 따른 연구 방향은 별도 업데이트에서 다룹니다. 체크포인트를 복원한 시연의 점수는 로컬 연구 결과로 기록합니다. 공식 제출은 주최 측의 초기화와 정책 인터페이스를 따릅니다. [챌린지 규정](docs/competition/RULES.md)
