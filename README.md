## 11월 27일 수집 마감 · 시연 45까지

시연 **44는 400전이**, **45는 사용자 요청으로 294전이**에서 정상 종료했습니다. 두 종료 슬롯을 저장했고 HDF5 전수 기술 검증을 통과했습니다. **[시연 44 전체 영상](docs/gallery/README.md#시연-44)**과 **[시연 45 전체 영상](docs/gallery/README.md#시연-45)**에서 1배속 영상을 비교할 수 있습니다.

- **44 · 파지 유지** · 집게를 약 67° 돌린 뒤 처음 물린 노란 밑단은 후퇴 중 빠졌습니다. 세 번째 파지는 종료까지 유지됐습니다. 손끝과 실제 소매 끝은 천 뒤에 가려졌습니다.
- **45 · 손목 추적과 밑단 파지** · 같은 전완 줄무늬에서 손목과 손 일부까지 보였고, 뒤이어 R1이 노란 밑단을 물려 짧게 이동하는 동안 같은 천 조각이 따라왔습니다. 이 상태를 종료 슬롯에 남겼습니다.
- **공통 병목 · 실제 소매 출구** · 시연 25의 1,200전이에서 시연 38의 399전이로 이어진 뒤, 40→44와 42→45로 갈라졌습니다. 지지와 시야는 개선됐지만 두 분기에서 실제 소매 둘레, 손의 통과, 같은 소매 끝의 팔꿈치 이동은 확인되지 않았습니다. 시연 38·42의 로컬 원점수 5점은 픽업에서 나왔고, 시연 44·45의 원점수는 0/50입니다. [분기별 화면과 착의 판정](docs/gallery/20261127-demo44-45-branches/README.md)

## 다음 실험 후보 · 영상 검토 후 선택

| 우선순위 | 시작 슬롯 | 첫 시험과 선택 기준 |
| --- | --- | --- |
| **1 · 소매 출구 확인** | **45 종료 294** · `finish-000294` | 복원·정착 뒤 두 파지와 같은 손목이 보이는지 확인합니다. R1을 고정한 채 R0 지지 손목의 기울기 한 축만 짧게 바꾸고, 같은 손끝과 실제 소매 둘레를 두 카메라에서 찾습니다. 손을 추적할 수 있는 상태에서 출구를 열 수 있는지 검증하는 후보입니다. |
| **2 · 파지 유지 재현** | **44 종료 400** · `finish-000400` | R0 몸판 지지와 R1의 노란 밑단 파지를 확인한 뒤 한 축으로만 짧게 움직입니다. 관절이 정착할 때도 같은 천이 남고 손끝을 볼 공간이 늘어나는지 확인합니다. 45 복원 후 파지나 시야가 사라지면 비교할 후보입니다. |
| **3 · 지지 방향 비교** | **38 종료 399** · `finish-000399` | 두 회차 모두 같은 슬롯과 R1 지시를 사용합니다. 한 회차는 R0 지지를 유지하고 한 회차만 지지 축 하나를 바꿔, 손목 가림과 실제 소매 둘레가 어떻게 달라지는지 비교합니다. 44·45처럼 출발 상태가 다른 회차를 원인 비교에 쓰기 어려울 때 선택합니다. |

접촉이나 가림이 불확실하면 **3–6전이**씩 확인합니다. 실제 소매를 통과한 손목, 안정된 파지, 이동 경로, 같은 소매 끝의 줄무늬 방향 이동이 확인되면 **12–20전이**로 이어갑니다. 팔꿈치 굽힘을 지난 뒤 두 카메라에서 확인하고 **중립 3전이** 후 같은 위치가 유지되는지 봅니다. 다음 실행은 영상과 분석을 검토한 뒤 선택합니다.
