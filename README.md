### 재개할 때 가장 먼저 판정할 장면

한쪽 손목 주름에 밑단이 얕게 걸린 장면을 먼저 찾습니다. 그쪽 로봇이 여유를 두고 받친 채 다른 로봇만 반대 손끝 앞의 노란 밑단을 2–4전이 옮깁니다. **조정 전후 두 손을 각각 추적해 ‘양쪽 유지’, ‘한쪽 이상 이탈’, ‘가림으로 미확인’을 구간 ID와 함께 기록합니다.** 시험 동작에 이르지 못하면 ‘미도달’로 남깁니다. 손끝이 가려지면 반대 헤드나 손목 시점에서 다시 보고, 먼저 건 쪽을 팔꿈치까지 밀기 전에 접근각이나 파지점을 바꿉니다. 양쪽 유지가 확인된 다음에 어깨·목으로 진행합니다. 몸판 밑단으로 두 손이 들어가는 중간 관찰과 각 손이 서로 다른 소매 출구로 나오는 공식 득점을 따로 기록합니다. ## 구간 검토와 데이터 수집

1. **재생** — 방금 끝난 구간의 5카메라 영상과 실제 사용한 지시를 봅니다. 왼쪽은 robot_1, 오른쪽은 robot_0입니다.
2. **판단** — Astra가 구간에서 표본으로 읽은 프레임을 근거로 의도와 실제 변화, 가려진 부분, 다음에 바꿀 한 가지를 제시합니다. 화면에서 구간의 성공·부분 진행·실패·불확실과 감독 평가 점수를 따로 읽습니다.
3. **피드백** — GPT 단독 모드는 구간 영상을 게시하고 다음 동작을 스스로 결정합니다. 시연 4–6에서는 개입 후 보류하면 같은 장면에서 기다리고, 피드백을 제출하면 해당 행동 경계에서 회차를 마칩니다. 사용자 피드백 모드에서는 구간마다 다음 동작을 승인합니다.
4. **기록** — 실행·구간 ID와 전이 범위로 영상, 지시, 분석, 다음 제안, 실제 채택된 피드백을 원본 행동 데이터에 연결합니다. 지난 구간은 필요할 때만 열고 회차별 JSONL을 내려받습니다. [실행 명령과 데이터 형식](docs/active/collection.md)

## 서버 리뷰와 다음 재개

현재 여섯 회차의 수집을 마쳤습니다. 각 회차의 HDF5 전이를 전수 검증했고, 원본·공식 평가·행동 기록과 구간 영상을 비공개 데이터셋에 보존했습니다. 복원한 갤러리에서 위 표의 시연과 `hold` 번호를 선택하면 같은 장면을 열 수 있습니다. 다음 서버에서는 이 기록을 먼저 검토하고 사용자가 새 실행을 요청할 때 새 ID로 시작합니다. [6회차 백업 확인서](docs/active/20261124-private-backup.json) · [새 서버에서 복원하기](docs/active/start.md)
