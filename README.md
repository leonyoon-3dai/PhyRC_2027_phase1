# PhyRC 2027 · 두 로봇의 티셔츠 착의

[![시연 영상 모음](docs/assets/demonstration-videos-menu.svg)](docs/gallery/README.md#시연-영상)
[![시연 결과와 분석](docs/assets/demonstration-analysis-menu.svg)](docs/gallery/README.md#시연-분석)

시연 29부터는 **양쪽 손목이나 양쪽 팔꿈치까지 옷이 걸린 상태**를 확인한 뒤 시작합니다. 두 로봇이 기존 지지를 살려 목과 어깨까지 빠르게 착의하고, 로컬 평가에서 **50점**을 기록하는 것이 목표입니다.

## 시연 29 이후 계획

| 단계 | 조작과 확인 기준 |
|---|---|
| 출발 상태 확인 | 양손목 걸침 또는 양팔꿈치 덮임이 두 시점에서 보이는 장면을 선택합니다. 체크포인트를 사용할 때는 복원·정착 후 같은 손, 밑단, 집게 관계를 다시 확인하고 출발 전이를 기록합니다. |
| 팔꿈치까지 착의 | 손목에서 시작하면 밑단 양쪽 끝을 해당 전완과 팔꿈치 쪽으로 옮깁니다. 한쪽 파지를 바꾸는 동안 다른 쪽이 옷을 받치고, 짧은 시험 동작에서 새로 잡은 천이 집게를 따라오는지 봅니다. 양팔꿈치가 이미 덮인 출발점에서는 목 접근으로 이어갑니다. |
| 목과 어깨 착의 | 양팔의 위치를 유지한 채 두 로봇이 밑단 중앙을 들어 실제 목둘레를 머리 위로 넘깁니다. 머리가 목둘레로 나왔는지 확인한 뒤, 각 로봇이 자기 쪽 어깨에 천을 안착시키고 몸통 쪽으로 내려 정리합니다. |
| 결과 확인 | 목둘레, 두 소매 밖의 손, 양쪽 어깨와 옷의 앞면을 여러 카메라에서 확인합니다. 시작점부터 각 단계까지의 새 전이 수와 실제 소요 시간, 평가 원점수와 착의 성공 판정을 기록합니다. |

시연 25의 1,200전이와 시연 26의 2,346전이 및 이후 체크포인트는 출발 후보입니다. 각 슬롯은 저장 시점의 기록으로, 양손목 또는 양팔꿈치 조건은 실제 복원 장면에서 확인해야 합니다. [체크포인트와 재파지 분석](docs/active/20261126-demo25-27-analysis.ko.md)

## 현재 진행

- **시연 28 · 진행 중.** 시연 25의 1,200전이 체크포인트를 복원하고 정착한 장면부터 양팔·팔꿈치, 목, 어깨 순으로 착의를 시도합니다. 새 회차는 0전이부터 세며, 200전이마다와 종료 직전에 저장합니다.
- **시연 27 · 종료.** 시연 25의 행동을 2,346전이까지 재생한 뒤 양팔 우선 접근을 시작했습니다. 2,389전이에서 종료 체크포인트를 저장했고, 로컬 평가에서 5/50점을 기록했습니다.

시연 28의 착의 결과와 후속 시연에 따른 연구 방향은 수집과 검증이 끝난 뒤 업데이트합니다. 체크포인트를 복원한 시연의 점수는 로컬 연구 결과로 기록합니다. 공식 제출은 주최 측의 초기화와 정책 인터페이스를 따릅니다. [챌린지 규정](docs/competition/RULES.md)
