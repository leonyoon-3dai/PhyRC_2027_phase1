## 시연 14 실험 계획 · R0 지지를 유지하며 오른손목 넣기

**시작 예정.** 클린 서버의 새 실행에서 0전이부터 시작합니다. 시연 13과 모델을 맞추기 위해 **GPT‑6.2 Sol Ultra와 카메라 설명**을 사용합니다. 초기화 직후 시드 43, 세 번째 테이블(+X, 인덱스 2), 셔츠–마네킹 마찰 0.35를 확인합니다. [새 서버 준비](docs/active/start.md) · [수집 절차](docs/active/collection.md)

**검증할 가설.** 시연 13에서 R0가 다시 잡은 아랫단은 오른주먹 아래까지 왔고, 종료 장면에서 오른손가락은 밑단 밖에 남았습니다. 시연 14에서는 **오른손 진입 구간에 R0가 아랫단 파지와 위치를 유지하고 R1만 윗단을 움직이면**, 이미 걸친 쪽을 살리면서 오른손도 손목까지 넣을 수 있는지 확인합니다. [시연 13 관측](docs/active/20261124-demo7-13-closeout.ko.md#영상에서-확인한-차이)

| 구간 | 조작과 확인 기준 |
|---|---|
| **1. 두 테두리 확보** | 옷을 들어 손 앞으로 옮깁니다. R0가 노란 아랫단 끝을 받치고 R1이 윗단을 잡습니다. 헤드와 손목 영상에서 오른주먹 앞에 두 테두리가 위아래로 벌어진 상태와 왼손 쪽 천의 지지를 확인합니다. |
| **2. R0 지지 유지, R1로 오른손 진입** | R0의 이동 채널과 그리퍼 명령을 중립으로 두어 기존 파지를 유지합니다. R1만 윗단을 한 번에 **2–4전이**씩 조정합니다. 매번 R0 집게의 실제 변위와 아랫단의 미끄러짐을 확인하고, 오른손끝과 마디가 같은 두 테두리 사이를 지나 손목까지 들어갔는지 봅니다. R0가 밀리거나 왼쪽 걸침이 풀리거나 가려지면 그 장면에서 동작을 멈추고 지지와 시야부터 복구합니다. |
| **3. 양손목 확인 후 목 쪽으로** | 두 손을 각각 따라가며 두 시점과 두 카메라에서 양쪽 걸침이 유지되는지 확인합니다. 확인되면 천에 여유를 남기고 팔을 따라 어깨·목 쪽으로 조금씩 당깁니다. 각 동작 뒤 양쪽을 다시 보고, 실제 V넥 테두리가 머리 위로 이동하는지 확인합니다. |

검토 화면에는 **R0 명령과 실제 집게 변위, 양손끝·마디와 밑단의 관계, 당긴 뒤 양쪽 걸침이 유지됐는지**를 남깁니다. 양손목이 밑단 안에 들어간 장면을 중간 목표로 삼고, 첫 소매와 목 통과는 공식 평가 항목으로 확인합니다. [공식 채점 기준](docs/competition/EVALUATION.md#score-items)

## 다음 작업

1. **입구 확인.** 한 손을 이동시키기 전에 두 노란 테두리가 손끝 앞에서 벌어져 있고 집게 몸체가 통로를 가리지 않는지 머리와 손목 카메라에서 확인합니다.
2. **한 손씩 추적.** 한쪽을 받친 채 반대 테두리를 짧게 움직입니다. 동작 전후에 손끝과 마디가 같은 입구를 지났는지, 다른 쪽 손목의 걸침이 유지됐는지 비교합니다. 가려지면 미확인으로 기록하고 카메라 각도나 파지점을 바꿉니다.
3. **양쪽 유지 후 목둘레 이동.** 두 손목이 짧은 조정 뒤에도 유지되는 것을 확인하고 어깨·목으로 진행합니다. 시연 2의 661전이처럼 소매 밖에 나온 손·손목은 공식 소매 통과와 대조합니다. 목을 넘길 때는 추적할 V넥 테두리를 먼저 정합니다. [시연 2의 득점 구간](docs/active/20261123-demonstrations.ko.md) · [공식 배점](docs/competition/EVALUATION.md)

바뀐 파지점, 손과 밑단의 상대 위치, 반대쪽 걸침, 공식 평가 점수를 구간 ID와 전이 범위에 연결합니다. 다음 서버에서는 보존한 영상을 먼저 확인하고 사용자 지시가 있을 때 새 run ID로 수집합니다.
