## 다음 작업

1. **입구 확인.** 한 손을 이동시키기 전에 두 노란 테두리가 손끝 앞에서 벌어져 있고 집게 몸체가 통로를 가리지 않는지 머리와 손목 카메라에서 확인합니다.
2. **한 손씩 추적.** 한쪽을 받친 채 반대 테두리를 짧게 움직입니다. 동작 전후에 손끝과 마디가 같은 입구를 지났는지, 다른 쪽 손목의 걸침이 유지됐는지 비교합니다. 가려지면 미확인으로 기록하고 카메라 각도나 파지점을 바꿉니다.
3. **양쪽 유지 후 목둘레 이동.** 두 손목이 짧은 조정 뒤에도 유지되는 것을 확인하고 어깨·목으로 진행합니다. 시연 2의 661전이처럼 소매 밖에 나온 손·손목은 공식 소매 통과와 대조합니다. 목을 넘길 때는 추적할 V넥 테두리를 먼저 정합니다. [시연 2의 득점 구간](docs/active/20261123-demonstrations.ko.md) · [공식 배점](docs/competition/EVALUATION.md)

바뀐 파지점, 손과 밑단의 상대 위치, 반대쪽 걸침, 공식 평가 점수를 구간 ID와 전이 범위에 연결합니다. 다음 서버에서는 보존한 영상을 먼저 확인하고 사용자 지시가 있을 때 새 run ID로 수집합니다.
