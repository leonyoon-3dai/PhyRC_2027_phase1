## 5. π₀.₅ 학습에서 먼저 맞출 계약

- E15 교사 입력은 현재 RGB5·손목 depth 패널1·공개 상태·depth 요약과 에피소드 문맥입니다. 학생의 기존 입력은 **RGB 3장과 state32**이므로 관측·기억 차이를 명시합니다.
- 학생은 두 로봇의 행동18을 모델 폭32에 맞추고 길이10 청크를 학습합니다. 14개 padding은 추가 관절이 아닙니다.
- `participant/pi05/data.py`는 현재 `approved_pipeline_test`만 받습니다. 실제 시연의 승인 상태를 추가하고 시험 자료와 구별해야 합니다.
- 같은 에피소드·복원 출처의 인접 프레임을 train/validation에 나누지 않습니다. episode와 `source_group`으로 분리합니다.
- 정규화는 train 자료로만 계산하고 학습·추론에 같은 변환을 씁니다. 드문 gripper 열기·닫기 명령을 유지합니다.
- 현재 추가 14차원과 에피소드 끝 반복 행동에 별도 loss mask가 없습니다. 유효 행동과 padding의 손실을 먼저 확인한 뒤 별도 비교 실험으로 수정합니다.
- 과거 63 scripted transition·30 update는 학습 연결 시험입니다. 이번 수집 자료로 착의 성능이 개선됐다는 근거로 사용하지 않습니다.

| 기록 | 필수 항목 |
|---|---|
| 가설 | 어떤 실패를 어떤 변경으로 줄이려는가 |
| 변경 하나 | 프롬프트·관측·행동 표현·청크·모델 중 이번에 바꾼 항목 |

| 출처 | run ID, 부모 시도, source group, 입력·모델·원본 SHA256 |
| 과제 결과 | 공식 평가 유효성, 항목별 점수, raw points, success, points/s |
| 데이터 품질 | 전체 전이 검사, 시각적 승인·제외 구간, 실패·복구 유형 |

| 판단 | 개선·악화·불확실, 표본 수와 다음 한 가지 변경 |

호출 시간이 줄어도 착의 점수가 늘지 않을 수 있습니다. **수집 효율**은 유용한 승인 데이터를 얻는 실제 시간으로, **제출 정책 성능**은 공식 points/s와 success로 따로 비교합니다. E15는 전체28분29.785초, 호출 경로18분25.822초, 환경9분08.946초입니다. 호출 경로는 모델 내부 추론시간이 아닙니다. 작은 표본이나 같은 출처의 재실행만으로 일반 성능 향상을 결론 내리지 않습니다.

RL은 기본 정책의 유용한 행동과 반복 가능한 reset·평가를 확보한 뒤 선택합니다. 허용된 점수·기하 기반 보상은 신뢰된 학습 환경에서 계산하고 actor·critic·추론 모델 입력이나 행동 정답으로 넘기지 않습니다. 기존 모방학습 기준선을 보존하고 동일 예산으로 비교합니다.
