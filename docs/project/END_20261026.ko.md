### 원본을 실제 output 경로로 복원

위 checksum 확인 뒤, 아직 같은 run 폴더가 없는 위치에서 실행합니다.

```bash
mkdir -p output/full_teleop output/policy_datasets output/training_export_requests
tar --zstd -xf \
  output/recovered-20261026/sessions/20261026-final/raw/20261026T061140_546693Z_ab9e06.tar.zst \
  -C output --no-same-owner --keep-old-files
```

이 예는 파지·운반 run만 복원합니다. 다른 run은 `session-summary.json`의 purpose와 complete를 먼저 확인합니다. 정상 원본의 exporter는 기존 HDF5를 덮어쓰지 않으므로 재개 전 부분 출력의 존재도 확인합니다. incomplete 원본을 수동으로 complete로 바꾸지 않습니다.
