# E23 종료 타이밍 · 재실행 길이와 환경 내부 비용

**짧은 prefix는 반복 준비 비용을 줄일 근거가 있다.** E23에서 실제 재실행한0→563의 환경 요청 합계는484.94초(8분05초),0→787은668.60초(11분09초)였다. 다만 더 이른 상태에서 목표까지 필요한 추가 모델 호출·행동까지 줄어든다는 뜻은 아니다. 현재 실행 변경이나 성능 개선 실험은 하지 않았다.

## 시간 필드의 범위

E23 실행 소스 `952ec8da68cdc0ef635d0d45329712eee006fd1f`의 저장된 profiler·collector wrapper·client 정의부터 확인했다. 아래는 **호스트에서 잰 호출 경과시간**이며 GPU kernel 시간이나 내부 모델 추론시간이 아니다.

| 필드 | 포함 범위와 중복 주의 |
|---|---|
| `environment_step_wall_s` | `env.step`과 profiler wrapper의 경과시간. observe와capture를 포함하고 dataset writer는 별도다. |
| `step_capture_wall_s` | `sensors.capture` 전체. render·Replicator·readback·대기를 내부에서 나누지 않았다. 순수 render 시간이라고 부르지 않는다. |
| `step_observe_without_capture_wall_s` | observe 전체에서 그 안의capture를 뺀 시간. 순수 공개 상태 직렬화 시간으로 확정하지 않는다. |
| `step_without_observe_wall_s` | env.step에서observe를 뺀 시간. 제어·physics·callback·평가·대기와 wrapper 비용이 분리되지 않았다. |
| `dataset_write_wall_s` | 기존 writer의append 호출 시간. 타이밍JSONL 자체의write/flush는 포함하지 않는다. |
| trace의 `environment_dispatch_wall_s` | 외부 요청·응답 구간이며 위env와writer를 포함한다. E23 소스는 종료stop/finish를 이 합계에 추가하지 않는다. |
| `collection_wall_elapsed_s` | writer 생성 뒤 누적시계다. 모델 대기 등 전이 사이 시간도 들어가므로 전이별 비용처럼 합산하지 않는다. |

`step_observe_wall_s`는capture를 포함하므로 두 값을 다시 더하지 않는다. attempt의`wall_s`도 전체 shell 실행시간과 같지 않다. 소스 replay의해시·읽기 등은 이 타이머 시작 전에 수행된다.

## 전체와 전이당 비용

분모는 닫힌 E23의1180전이 전체이며 시작 구간을 제거하지 않았다. 기록 인덱스0–1179와tick 증가12가 연속이다. 매 전이observe1회·capture1회·observe밖capture0회이며, env 분해 합의 **산술 오차는0**이었다. 이것은 타이머 정확도·계측 오버헤드0이나 OFF 대비 검증을 뜻하지 않는다.

|E23에 실제 기록된 경계|누적요청|env+writer 합(초)|환경dispatch 합(초)|해석|
|---|---:|---:|---:|---|
|430|43|339.760|367.399|E23 경로의 실제 재실행. E07/430과는264 이후 행동이 다르다. |
|563|61|446.028|484.937|E18/563과 같은 행동 prefix 계보의 새 재실행 실측. 천 상태 동일성은 아님. |

네 경계가 모두 기존 요청 끝과 일치해 부분 요청 시간의 비례배분은 하지 않았다.1179와563의 기록된 차이는616전이에 대해 **env+writer513.577초(8분34초), 외부dispatch546.928초(9분07초)**다. 두 숫자는 포함 범위가 다른 계측이며 신뢰구간이나 미래 절감시간의 상·하한이 아니다.

430까지 줄이는 같은 E23 경로 계산은749전이에 대해619.845초/664.466초 차이다. 그러나 **실제 후보 E07/430에는 이 값을 직접 대입할 수 없다.** E07과E23은264 이후 행동과 천 상태가 다르므로 이번 자료는 길이에 따른 비용 규모만 보여준다. [E07·E15의 다른 출발 후보](../../collection/research/2026-11-07-earlier-support-startpoints.ko.md)

미래의 pure replay에서는 요청 묶음·현재 천/접촉/화면·대기 비용이 달라질 수 있다. 더 이른 출발로 돌아가면 목표까지의 추가 판단과 조작이 늘 수도 있다. 따라서 짧은 prefix는 다양한 방법을 비교할 준비 비용의 근거이지, 현재 진전이 큰 continuation을 대체해야 한다는 결론이 아니다. E24 파일·실행은 확인하거나 변경하지 않았다.

단일 실행의 혼합 장면 통계이며 p50/p95는 선형보간 표본분위수다. 반복실험 신뢰구간·계측OFF A/B·가속효과 검증은 없다. 입력은 닫힌 step_timings와 최종 segment의 시간 필드·attempt 상위 wall 필드로 한정했고, HDF5·평가 데이터·audit·원시 로그·모델 내부 추론을 읽지 않았다.
