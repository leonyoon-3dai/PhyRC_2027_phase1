## 다음에 할 일

사용자가 클린 서버에서 작업을 재개하면 공식 환경과 공개 관측을 확인하고, 기존 제한 실행기에 Codex CLI의 Astra를 연결합니다. 작은 동작·정지·정상 저장을 확인한 다음 접근·파지·들기의 짧은 시도로 넘어갑니다. Chrome UI는 사람 관찰·직접 시연·수정 수단으로 유지합니다.

## 다음 세션의 최소 산출물

공개 관측으로 행동을 생성한 한 번의 짧은 수집, 실제 적용 명령이 담긴 정상 종료 HDF5, 정보 경계·시간 동기화 검사, 실행 명령과 추적 기록입니다. 이것을 착의 성공으로 표시하지 않습니다. 이후 짧은 시도 10회로 자동 수집 효율을 판단합니다.

이번 변경은 문서 정리입니다. 서버를 생성하거나 실행 상태를 조회하지 않았고, 새 수집·학습·평가·제출을 수행하지 않았습니다. 현재 서버 전원이나 원격 자료 보존 여부를 추정하지 않습니다.

과거 세션의 명령·자료·측정은 [세션 기록](sessions/), [11월 3일 종료 기록](END_20261103.ko.md), [이전 결과](RESULTS.ko.md)에 남아 있습니다. 당시의 작업 우선순위는 현재 README를 대체하지 않습니다.
