# 2026-11-03 · A10에서 L40S로 전환

A10은 L40S보다 이전 세대의 GPU다. 사용자는 다음 실험을 L40S 서버에서 진행하기로 결정하고, A10 서버는 직접 종료하기로 했다. GPU 세대만으로 이번 문제의 원인을 단정하지 않는다.

이번 A10 환경에서 공식 build·prepare·smoke는 통과했다. Chrome 영상과 API 키 없는 규칙 기반 텍스트 명령에 따른 로봇 움직임도 확인했지만, 영상에 심한 모래알 같은 노이즈가 있었다. 설치된 NVIDIA 드라이버 570.148.08은 Isaac Sim RTX가 요구하는 범위보다 낮아 드라이버 검사를 임시로 우회한 진단이었다. 최근 구간의 시뮬레이션 속도는 약 0.054 simulation seconds/wall second였으며, L40S와 조건을 맞춘 비교는 아니다.

진단 원본은 265 transitions, 3,448 raw states로 complete=true 저장됐다. RGB-D 변환과 학습 적합성 검수, 착의 성공과 공식 점수, 물리적 원위치 복귀는 확인하지 않았다. 원본과 이번 시제품 코드는 A10 서버에만 있으며 GitHub 또는 별도 저장소에 업로드했다고 주장하지 않는다.

다음 L40S 서버에서는 NVIDIA 드라이버와 Vulkan/NVENC 지원을 먼저 확인하고, 이전에 사용하던 Chrome 조작 및 기록 경로를 복원한 뒤 화질과 반응을 다시 확인한다. 서버의 IP와 포트는 새로 확인한다. 새 서버의 드라이버 호환성은 아직 검증되지 않았다.
