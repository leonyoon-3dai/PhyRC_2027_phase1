## 추가 판단은 도움이 됐는가

초기 5회는 손 쪽 경계 낮추기, 손목 roll, 반대쪽 yaw 등 새로운 방향을 시험했다. 이후에는 접근·팔 당기기·올리기와 당기기의 결합·되돌리기 등을 시험했다. 양측 국소 파지는 유지됐으나 입구가 좁아지고 손가락이 가려지는 문제를 해소하지 못했다. **새로운 방법과 실패 조건을 관측하는 데는 도움이 됐지만, 착의 진전이나 추가 점수의 증거는 얻지 못했다.**

마지막 actor는 현재 파지로 손 통과를 확인하지 못하고 유용한 재파지 방법을 찾지 못했다는 이유로 종료했다. 이것은 현재 정책의 국소적인 판단이며 모든 유용한 움직임이 불가능하다는 증명은 아니다. 남은 결정 예산이 있었으므로 **동일 조건의 예산 확대만 권하기는 어렵다**. 다음에는 입구·그리퍼의 여유를 바꾸는 구체적인 방법을 비교하고, 이후 예산은 사용자가 분석을 보고 결정한다. [현재 수집 계획](../../COLLECTION_PLAN.md)

E29의 첫 현재 관측은 E28/738과 공개 로봇 상태·영상에서 가깝게 맞았으나 정확한 천 상태 복원이 아니다. 새 actor의 문맥도 다르므로 차이를 추가 예산 하나의 인과 효과로 단정하지 않는다. 같은 source group의 관련 시연이며 독립 성공 사례로 더하지 않는다.

## 사용자 제안과 준비한 기능

사용자는 실행 중 노란 경계를 손목 아래로 낮춘 뒤 대각선으로 회전하며 올리는 경로를 제안했다. [제안 원문과 조건부 비교안](../../collection/research/2026-11-13-user-diagonal-entry-feedback.ko.md)을 보존했다. 당시 actor에 실시간으로 삽입하지 않았으며, E29의 낮추기·회전·올리기는 기존 전략이 독립적으로 선택한 동작이다. 올리기에는 팔 당기기와 다른 손 쪽 이동이 함께 들어갔으므로 사용자가 제안한 분리된 경로의 통제 시험으로 해석하지 않는다.

향후 지시 삽입 기능은 사용자의 요청에 따라 **별도 개발 공간에서만 준비**했다. [미적용 패치와 검증 자료](../../collection/research/candidates/20261113-actor-feedback/README.ko.md)는 다음 새 판단 경계 전달, 고정된 깊이 질의 중 지시 변경 방지, 개입·전달 여부와 계보 보존을 포함한다. CPU 353개 검사와 독립 검토를 통과했으나 실제 모델·GPU 연결은 미검증이고, main 실행 코드나 E29에 적용하지 않았다.
