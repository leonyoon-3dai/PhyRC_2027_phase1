# E35 준비: 운반 뒤 아래 자유 구간을 넓혀 약간 위에서 측면 접근

**사용자의 새 지시가 E34 이후 중지와 E35 취소를 해제했다.** 먼저 정리본을 GitHub에 게시한 뒤, 기존 수집 경로로 옷 아래를 넓게 펼치고 약간 위에서 옆으로 같은 마네킹 손목에 접근하는 비교를 **최대5회, 약3–4시간 범위**에서 진행하며 중간 피드백을 반영한다. 과거 E34 중지 기록은 당시 이력으로 보존한다. 이 문서는 첫 시도의 CPU 준비 기록이며 실제 수집 시작·성과가 아니다.

연구 재정비 계획 전체를 구현하거나 실시간 피드백 큐를 활성화하는 요청으로 확장하지 않는다. 한 시도씩 정상 마감·QC·별도 평가·보존·관측 분석 후 다음 방법과 출발점을 정한다. 사용자 피드백은 해당 run과 공개 관측 경계에 연결해 다음 시도 준비에 반영하며, 실행 중 코드·프롬프트를 바꾸거나 두 번째 제어원을 시작하지 않는다.5회는 상한이며 남은 결정을 다음 run에 합산하지 않는다.

## 723을 선택한 공개 관측 근거

[E34 시각 리뷰](../../collection/reviews/20261114-astra-middle-grip470-retain-001.ko.md)의 지정 head/wrist/overview를 다시 확인했다.723은 테이블 밖 운반 뒤이고 D13의 추가 높이·pitch 조정 전이다. 양 jaw 부근 천과 길게 세운 노란 경계가 남고, 선택 손이 잡힌 모서리/housing에 가까워져 가려지기 전이라 형상·방향을 비교할 여유가 보인다.671·697은 그 직전 운반의 연속 관측이며 실제 실행에서는 새 replay 중 다시 생성한다.

787에서는 손이 경계 옆으로 가까워졌고815 이후에는 손가락 일부가 천·jaw 부근에 가려졌다. E34 마지막835/836은 짧은 하강과 횡보정 뒤에도 손목 걸침·전완 진행이 확인되지 않아 단순히 최신이라는 이유로 출발점으로 선택하지 않는다.723으로 되돌리는 것은 성공 확률의 증명이 아니라 접촉 전 형상 비교 여유를 확보하려는 선택이다.

E28/632는 더 비스듬하고 넓게 보이는 자유 구간 후보를 제공하지만 E34와 파지 자체가 다르다. 첫 비교는 E33에서 바꾼 파지가 운반까지 유지된 E34 계보로 제한한다. E28/380과 E33 말단은 준비·운반을 더 반복해야 하므로 첫 선택에서 제외한다. 이 대안들을 실패하거나 불가능한 출발점으로 판정한 것은 아니다.

**기존에 실제 시험한 부분:** E34의 세로 형상·운반·높이 조정·근접 정렬·짧은 하강. **이번 비교 가설:** 아래 자유 구간의 폭을 먼저 유지한 뒤, 같은 손보다 약간 위에서 측면으로 접근하는 순서. “넓은 입구가 이미 확보됐다”, 노란 윤곽이 몸통 밑단임이 확정됐다는 뜻은 아니다. 새 replay의 현재 공개 RGB-D·로봇 상태에서 지지·폭·깊이·같은 손과 연결 전완을 다시 판단한다. 화면 위아래·좌우를 고정 world 축이나 특정 속도값으로 치환하지 않는다.

## 실행 기록

**현재는 CPU 준비 완료·미실행이다.** 모델·GPU·시뮬레이터를 시작하지 않았다. 실제 실행 source commit, clean 여부, GitHub 선게시 확인, UTC 시작과 launcher 식별자는 실행 담당자가 시작 확인 뒤 추가한다. 전략 구현·CPU 검증 결과도 해당 source에 맞춰 기록한다.

재실행은 정확한 천 physics checkpoint 복원이 아니다. 시도별 원본을 별도 마감·검증·백업하고 같은 E28 source group을 유지한다. 점수·공개 관측·단계 의도·기술 QC·학습 승인을 분리하며, E09/E32 불완전 원본은 계속 출처에서 제외한다.
