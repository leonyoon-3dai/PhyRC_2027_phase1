## 준비된 후보와 아직 결정하지 않은 것

1. **한 팔의 목표 연속성.** E27/928·과거 관측890/906에서 같은 팔의 진행을 우선하는 후보를 준비했다. 특정 손이나 좌표는 검수자가 주지 않고 새 정책이 현재 공개 관측으로 고른다. 가림 속의 유한 진행·복구와 정당한 목표 전환을 허용한다. 목표 순서 비교이며 새 파지나 성과 보장이 아니다. 사용자 중지 지시로 실행을 보류했고, 오프라인 검토 후 출발점·예산·전략을 재선택한다. [후보와 범위](../collection/research/2026-11-07-e27-single-arm-continuation.ko.md)
2. **파지 배치와 의복 경로.** 운반 이후 같은 면의 접힘과 팔–경계 관계가 정체되는 근거가 쌓이면, 테이블의 몸판 지지를 유지하며 안내 쪽 파지를 소매 방향 경계 후보로 실제 바꾸는 비교를 검토한다. 아직 구현·실행하지 않았고, 보이지 않는 파지 위치나 입구 정체를 만들어 주지 않는다.
3. **좌표 표현 보조.** 손목 방향 보조는 기존 공개 depth와 정적 로봇 기구학을 계산하는 후보다. 새 센서나 옷의 숨은 면 정보를 추가하지 않는다. 방향 해석 오류가 실제로 확인될 때 같은 출발·같은 전략에서 별도 비교한다. main에는 통합하지 않았다. [검토와 한계](../collection/research/2026-11-07-public-wrist-motion-aid-review.ko.md)

한 팔 후보 `0c51a1a`는 E27 종료 후에만 통합했다. [격리 전체325 CPU 검사](sessions/20261107-single-arm-progress-validation.json)와 [통합본166개 소스 해시 일치](sessions/20261107-single-arm-integration-verification.json)를 확인했지만 실제 모델·물리·득점 효과는 미검증이다. 손목 보조의 별도335검사를 현재 한 팔 코드의 검사 수에 더하지 않는다.

[조건부 방법 비교 원문](../collection/research/2026-11-07-e27-next-method-options.json)은 E27의842경계까지만 검토했던 당시 기록이다. 이후 결과나 최신 중지 지시를 알고 작성한 분석으로 해석하지 않는다. [BEHAVIOR 우승 솔루션 참고](../collection/research/2026-11-07-behavior-champion-text-review.ko.md)는 과제 차이를 확인하며 활용하고, 외부 시연의 좌표나 숨은 상태를 실제 actor 입력으로 복사하지 않는다.

장기적으로는 [0→5→10 조합 계획](../collection/research/2026-11-07-composable-scoring-data-plan.ko.md)을 따른다. 점수만 같은 구간을 바로 잇지 않고 공개 상태·지지·의복 방향의 호환 가설을 기록한 뒤 새 환경에서 재실행·검증한다. 지금 합성 시연 생성이나 새 정책 학습은 하지 않았다.
