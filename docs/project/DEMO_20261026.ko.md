**확인된 성과는 양팔 파지·들기·사람 쪽 운반입니다.** 소매 삽입·목 통과·완전 착의·공식 점수는 확인하지 않았습니다. 다음 연습은 이 운반 구간을 더 짧고 반복 가능하게 만들고 소매 진입으로 이어가는 것입니다.

## 조작에서 발견한 문제와 다음 UI

시뮬레이션이 실제 시간보다 약 10배 느리고, 로봇 회전에 따라 화면상의 전후좌우가 달라져 접근에 시간이 걸렸습니다. 아주 짧은 키 입력이 한 제어 시점 안에서 눌렸다 해제되면 이동 명령이 사라질 수도 있었습니다.
