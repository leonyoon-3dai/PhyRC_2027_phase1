# 사건 구간을 여러 카메라로 내보내기

[갤러리](README.ko.md) · [내보내기 도구](../../scripts/export_gallery_event.py)

완전히 종료되고 전수 검사를 통과한 시도의 특정 구간을 **로봇 0·1의 머리/손목 카메라 2×2 화면**으로 만듭니다. 각 카메라 이름과 전이 경계·에피소드 상대 시간을 표시하며, GIF는 페이지에서 반복 재생하고 MP4는 재생 위치를 조절할 때 사용합니다. 라이브 화면 연결이나 새 모델·물리 시뮬레이션은 필요하지 않습니다.

## 실행

저장소 루트에서 다음과 같이 실행합니다. 기존 출력 폴더를 덮어쓰지 않으므로 새 사건에는 새 이름을 사용합니다.

```bash
PYTHONPATH=.:src/PhyRC_Sim .venv/bin/python scripts/export_gallery_event.py \
  output/collections/20261106-astra-coordinated-fresh-001 \
  --output docs/gallery/assets/20261106-astra-coordinated-fresh-001-multiview \
  --start 620 --end 700 --fps 5 --tile-size 256 --colors 64
```

| 옵션 | 의미 |
|---|---|
| `--start`, `--end` | 포함할 처음·마지막 **전이 경계**, 양끝 포함 |
| `--fps 5` | 20Hz 원본의 모든 선택 프레임을 4배 느리게 재생 |
| `--tile-size 256` | 카메라별 정사각형 표시 영역. 비율 유지·전체 화면 보존 |
| `--colors 64` | GIF 색상 수. MP4 색상 제한과 별개 |
| `--validation` | 기본 `capture/validation.json` 외의 기존 전수 검사 파일 지정 |
| `--cameras` | 허용 카메라 중 서로 다른 4개를 좌상·우상·좌하·우하 순서로 지정 |

출력은 `preview.gif`, `event.mp4`, `provenance.json`입니다. FFmpeg·필터 스레드는 각각 2개로 제한합니다. 비디오의 프레임 수, GIF의 전체 프레임·반복·표시 시간을 생성 뒤 검사합니다. 큰 GIF가 만들어지면 더 짧은 사건 경계를 선택해 새 폴더로 내보냅니다. 파일 크기를 줄이려고 원본 프레임을 자동 생략하지 않습니다.

## 정확한 프레임 경계

- 경계 **0**은 `obs[0]`, 첫 행동 직전입니다.
- 경계 **k > 0**은 `next_obs[k-1]`, k번째 전이가 끝난 직후입니다.
- `k < N`이면 같은 카메라의 `obs[k]`와 픽셀이 동일한지도 확인합니다.
- 마지막 경계 **N**도 선택할 수 있습니다. `obs[N]`은 없으므로 `next_obs[N-1]`을 사용합니다.

620~700은 81장입니다. 처음·마지막 관측의 시간 차이는 4.00초이며, 마지막 표본도 1프레임 길이로 표시하므로 5fps 파일의 재생 길이는 **16.2초**입니다. 표시 시간은 경계/20으로 계산한 에피소드 상대 시간이며, 초기화 시간을 포함한 공개 관측 절대 시계와 다릅니다. 모델 응답 대기는 들어 있지 않습니다.

카메라 화면을 자르거나 새 동작·중간 프레임을 합성하지 않습니다. 크기 조절은 nearest-neighbor이며 비율이 다른 입력은 여백을 둡니다. 텍스트는 카메라 픽셀 바깥의 별도 띠에 표시합니다. 원본 256×256을 크게 보여 주어도 새 세부 정보가 생기지는 않습니다.

## 닫힌 원본만 사용

도구는 HDF5를 열기 **전에** 완료된 즉시 수집 manifest, 오류 없는 전체 검사 결과, manifest·검사 결과와 실제 `policy.hdf5`의 일치하는 SHA256을 요구합니다. HDF5 파일·에피소드 완료 속성과 표본 수도 대조하며 처리 중 원본 변경을 거부합니다. 실행 중인 시도의 HDF5를 이 도구로 열지 않습니다.

원본에서 읽는 영상 데이터는 지정된 공개 RGB뿐입니다. 평가·audit·배치·시드·물체 기하·actor 원문은 복사하지 않습니다. 공개 provenance에는 원본·검사·도구·산출물 SHA와 카메라·선택 범위·인코딩 조건을 기록하고 로컬 절대 경로는 넣지 않습니다. 공식 점수와 성공 여부는 영상에서 추론하지 않고 별도로 검토한 기록에 연결합니다.

진행 중 사건은 현재 수집기가 별도 파일로 내보낸 공개 PNG를 사용하거나 정상 종료 뒤 이 도구로 내보냅니다. 이 도구 자체가 실시간 게시, 시도 종료, GitHub 업로드를 수행하지는 않습니다.

## 갤러리 게시

실제 GIF가 생성되고 검토된 뒤 아래처럼 **이미지 자체에 링크를 걸지 않고** 넣으면 스크롤하면서 볼 수 있습니다. MP4와 출처는 아래에 별도로 연결합니다.

```html
<img src="assets/실제-사건-ID/preview.gif" width="960"
     alt="실제 실행·관측한 사건·선택 경계·배속">
```

갤러리의 `docs/gallery/assets/*/event.mp4`는 저장소의 MP4 무시 규칙에서 제외됩니다. **검토한 해당 파일만** 명시적으로 추가합니다. 업로드 전 사건명·현재/최종 평가 구분·카메라·원본 경계·배속을 함께 확인합니다. 영상 생성·파일 기술 검사·실제 파지나 착의 성공은 각각 다른 결과입니다.
