# 시연 26 계획 · 밑단 중앙을 들어 목부터 착의

시연 26은 사용자 시작 지시가 있을 때 실행한다. 새 서버에서 시연 25의 종료 기록을 복원하고, 동일한 초기 배치에서 시연 25의 행동을 **2,346전이**까지 재생한다. 이 끝점의 여러 카메라에는 파란 몸판이 양팔 앞에 있고 노란 천이 두 집게 가까이에 남아 있었다. 손끝과 입구 안쪽은 가려졌으므로 새 장면에서 양쪽 파지와 팔의 위치를 먼저 확인한다. [시연 24–25 종료 기록](20261126-demo24-25-closeout.ko.md) · [새 서버 준비](start.md)

| 순서 | 조작 | 다음 단계로 넘어갈 관찰 기준 |
|---|---|---|
| 1. 밑단 중앙 들어 올리기 | 두 로봇이 노란 몸통 밑단 중앙의 양옆을 받친다. 한쪽씩 파지 위치를 바꾸며 반대편 지지를 유지한다. 두 집게가 함께 들어 밑단 중앙이 인체 정중선을 따라 올라갈 여유를 만든다. | 좌우 천이 각각 집게를 따라 움직이고, 중앙부가 함께 올라가며 실제 목둘레의 경계를 여러 뷰에서 추적할 수 있다. |
| 2. 목 통과 | 팔 쪽 지지와 천의 여유를 유지하면서 실제 목둘레를 정수리 앞으로 안내해 머리 위로 넘긴다. 손목·헤드·오버뷰에서 목둘레와 몸통 밑단을 따로 추적한다. | 얼굴과 목이 열려 있고, 목둘레 테두리가 목 둘레에 안착한 모습이 두 시점에서 확인된다. 가려지거나 걸리면 당기는 힘을 먼저 줄이고 파지나 방향을 조정한다. |
| 3. 양쪽 어깨 안착 | 각 로봇이 자기 쪽 어깨로 천을 보낸다. 필요한 경우 한쪽의 지지를 유지한 채 다른 쪽부터 조정하고 반대편을 반복한다. | 목둘레가 유지되고, 양쪽 어깨와 팔 주변에 천이 각각 자리 잡는다. 두 손이 대응하는 소매 밖에 보이는지도 확인한다. |
| 4. 몸통 착의 완료 | 두 로봇이 각자의 자락을 몸통 쪽으로 펼쳐 내려 안착시킨다. 필요할 때 지지를 한쪽씩 풀어 주름과 비틀림을 정리한다. | 목둘레와 양 어깨가 유지되고 몸통을 덮으며 옷의 앞면이 앞을 향한다. 지지를 푼 뒤 같은 상태가 유지되는지 확인한다. |

모델은 시연 25와 같은 GPT‑6.2 Sol Ultra, 5개 공개 카메라, 손목 깊이 패널을 사용한다. 행동당 상한은 20전이, 검토 구간은 최대 5행동·80전이로 둔다. 머리·목·어깨에 가까울 때는 짧게 조정하고 새 영상에서 천이 따라왔는지 확인한다. 공식 평가와 시각적 단계 판정은 따로 기록한다. [실행 프롬프트](../../participant/collection/prompts/demo26_center_hem_neck_first.txt) · [공식 평가](../competition/EVALUATION.md)

## 전 구간 체크포인트

- 원본 재생 중에는 **100전이마다**, 그리고 **2,346전이 분기점**에서 저장한다. 저장한 뒤 같은 상태에서 재생을 이어간다.
- 새 착의 구간은 **움직임이 있었던 모든 검토 구간 끝**에서 저장한다. 목 통과·양 어깨·몸통 등 정확한 추가 경계가 필요하면 시연 중 전이를 예약한다.
- 정상 종료 직전에도 저장한다. 체크포인트는 비공개 근사 복원용이다. 복원 성능은 별도 비교 시험으로 확인한다. [저장 예약과 상태 조회](collection.md#시연-중-체크포인트-저장)

### 시작 명령

새 서버에서는 [새 서버 준비](start.md) 절차로 검토 저널과 JPEG 프레임을 복원한다. 이어서 [시연 24–25 비공개 백업 확인서](20261126-demo24-25-private-backup.json)의 시연 25 원본을 고정 revision에서 받아 SHA-256을 대조하고, `participant/ops/artifacts.py restore`로 빈 디렉터리에 푼다. 복원한 `output/collections/20261125T225836Z-demo25-sol-ultra`와 `output/operator-traces/20261125T225836Z-demo25-sol-ultra` 아래의 원본 운영 기록을 새 서버의 같은 경로에 배치한다. JPEG가 들어 있는 `segment-frames`를 유지한다. 갤러리 부모 링크에는 복원된 시연 25 저널이 필요하다.

GPU 검증을 끝내고 사용자 시작 지시를 받은 뒤 저장소 루트에서 실행한다. 검토 영상은 최근 160전이의 4배속 가로형 GIF를 사용한다.

```bash
source_run=20261125T225836Z-demo25-sol-ultra
start_step=2346
phyrc_run_id="$(date -u +%Y%m%dT%H%M%SZ)-demo26-sol-ultra"
checkpoint_args=()
for ((step=100; step<start_step; step+=100)); do
  checkpoint_args+=(--checkpoint-step "$step")
done
checkpoint_args+=(--checkpoint-step "$start_step" --checkpoint-step finish)

export PATH="$PWD/.runtime/codex-0.166.0/node_modules/.bin:$PATH"
PYTHONPATH=.:src/PhyRC_Sim .venv/bin/python -m participant.collection.codex_client \
  --run-id "$phyrc_run_id" --mode dressing --gpt-only --until-full-score-or-feedback \
  --model gpt-6.2-sol --effort ultra --actor-backend exec --plan-size 1 \
  --wrist-transfer --replay-prefix-run "$source_run" --replay-prefix-steps "$start_step" \
  --gpt-task-prompt participant/collection/prompts/demo26_center_hem_neck_first.txt \
  --camera-briefing --named-actions --wrist-depth-panel --segment-review-dir output/segment-review \
  --segment-decisions 5 --segment-steps 80 --post-action-settle-steps 0 \
  --max-steps 18000 --model-timeout 180 --checkpoint-every-review "${checkpoint_args[@]}"
```

실행자가 분기 영상을 확인하고 체크포인트 수신을 검증한다. 종료 후 HDF5 전체 전이 검증, 공식 평가 확인, 검토 ZIP 생성과 비공개 보존은 기존 수집 절차를 따른다. [수집 마감 절차](collection.md#마감과-데이터-확인)
