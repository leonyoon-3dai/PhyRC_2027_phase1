# 시연 27·28 동시 실행 성능

NVIDIA L40S 한 장에서 시연 27과 28을 별도 시뮬레이터로 실행하고, 시연 28의 처리량을 기록했습니다. 시연 27은 처음에 시연 25의 동작을 연속 재생했고, 2,346전이 이후에는 시연 28과 마찬가지로 GPT가 각 행동을 결정했습니다. 동시 실행 표본을 모은 뒤 시연 27을 2,389전이에서 종료하고 마지막 체크포인트를 저장했습니다.

## 동시 실행 실측

시연 28의 2–106전이에서 새 전이 104개와 행동 요청 23회를 측정했습니다. 전체 처리량에는 행동 사이의 GPT 응답 대기, 검토 영상 처리, 관측 전달 시간이 포함됩니다. 시뮬레이터 전이 시간은 환경의 동작과 관측을 처리하는 구간의 중앙값입니다.

| 시연 27의 상태 | 시연 28 표본 | 전체 처리량 | 시뮬레이터 전이 중앙값 | 시연 27과 행동 처리 시간 중첩률 |
|---|---:|---:|---:|---:|
| 동시 실행 전체 | 104전이 · 23회 | 7.10전이/분 | 1.027초/전이 | 49.7% |
| 원본 행동 연속 재생 | 52전이 · 12회 | 6.52전이/분 | 1.129초/전이 | 93.1% |
| 두 시연 모두 GPT 제어 | 52전이 · 11회 | 8.59전이/분 | 0.985초/전이 | 0% 관측 |

중첩률은 시연 28의 행동 요청을 시뮬레이터가 처리한 시간 중 시연 27도 행동을 처리한 비율의 추정값입니다. 요청과 평가 표본의 시각을 정렬했으며 GPU 커널 사용률은 따로 측정하지 않았습니다.

두 시연의 GPT 요청이 실제로 겹친 시연 28 요청 11회의 처리 시간 중앙값은 **28.9초**, 동시 실행 중 요청이 겹치지 않은 11회는 **33.0초**였습니다. 겹친 요청은 생성 토큰도 적었으므로, 이 표본에서는 중첩에 따른 지연 증가가 관측되지 않았다고 해석합니다. 처리 시간에는 CLI 시작, 네트워크와 서비스 대기, 생성이 포함됩니다.

## 단독 실행 비교

시연 27의 HDF5 검증과 보존 압축이 끝난 뒤 시연 28의 단독 표본을 수집하고 있습니다. 두 조건에서 각각 100전이 이상과 행동 요청 15회 이상을 확보해 비교합니다. 표본은 시연 28의 실행 성능을 측정하는 데 사용하며, 착의 결과와 후속 연구 방향은 종료 후 기록을 검증한 뒤 정리합니다.
