# 시연 27·28 동시 실행과 단독 실행 성능

NVIDIA L40S 한 장에서 두 시연을 별도 시뮬레이터로 돌리고, 시연 28의 진행 시간을 측정했습니다. 동시 실행 전체와 비교하면 단독 실행은 **분당 7.10전이에서 7.37전이로 약 3.8% 빨랐습니다.** 100전이로 환산하면 **14분 5초에서 13분 34초로 약 31초** 차이입니다.

## 측정 결과

| 상태 | 시연 28 측정 범위 | 행동 요청 | 실제 소요 | 전체 처리량 | 시뮬레이터 전이 중앙값 |
|---|---:|---:|---:|---:|---:|
| 동시 실행 전체 | 2–106 · 104전이 | 23회 | 14분 39초 | 7.10전이/분 | 1.027초/전이 |
| 시연 27이 원본 행동 연속 재생 | 2–54 · 52전이 | 12회 | 7분 58초 | 6.52전이/분 | 1.129초/전이 |
| 두 시연 모두 GPT 제어 | 54–106 · 52전이 | 11회 | 6분 3초 | 8.59전이/분 | 0.985초/전이 |
| 시연 28 단독 | 188–289 · 101전이 | 23회 | 13분 42초 | 7.37전이/분 | 0.987초/전이 |

전체 처리량은 측정 구간 첫 행동의 처리 시작부터 마지막 행동의 완료까지 계산했습니다. GPT 응답 대기, 검토 영상 처리, 관측 전달, 구간 안의 체크포인트 저장 시간이 포함됩니다. 시뮬레이터 전이 중앙값은 환경에서 한 전이의 동작과 관측을 처리한 시간입니다. 동시 실행의 두 하위 구간을 각각 측정할 때 구간 사이의 대기가 빠지므로, 두 하위 구간 시간을 더한 값과 전체 시간에는 차이가 있습니다.

시연 27이 연속 재생할 때는 시연 28의 행동 처리 시간 중 **93.5%**가 시연 27의 처리와 겹쳤습니다. 두 시연이 모두 GPT로 제어된 구간에서는 실제 행동 처리 중첩이 관측되지 않았고, 시뮬레이터 전이 시간은 단독과 비슷했습니다. 중첩률은 행동 요청 처리 구간의 시각을 정렬한 추정치입니다. GPU 커널 사용률을 별도로 측정하지 않았습니다.

## GPT 응답이 겹친 경우

시연 28의 모델 요청 중 시연 27의 요청과 실제로 겹친 11회는 CLI 처리 시간 중앙값 **28.86초**였습니다. 시연 28 단독의 21회는 **28.60초**였습니다. 겹친 시간의 중앙값은 **24.66초**였고, 이 표본에서는 요청을 병행해도 각 응답 시간이 크게 늘지 않았습니다. CLI 측정에는 로컬 시작, 네트워크, 서비스 대기와 생성이 함께 포함됩니다.

단독 표본에도 **99.5초**가 걸린 모델 요청이 한 번 있었습니다. 이 대기를 전체 처리량에 포함했습니다. 구간마다 장면, 행동 길이, 생성 토큰 수와 서비스 응답이 달라서, 이 한 번의 전후 비교로 동시 실행의 일반적인 지연을 확정하기는 어렵습니다.

## 비교 경계

시연 27은 동시 표본을 모은 뒤 2,389전이에서 종료하고 마지막 체크포인트를 보존했습니다. 시연 27의 HDF5 검증과 보존 압축, 같은 서버에서 진행한 영상 인코딩이 끝난 뒤 단독 표본을 측정했습니다. 이 기록은 실행 성능 비교입니다. 시연 28의 착의 결과와 연구 방향은 별도 업데이트에서 정리합니다.
