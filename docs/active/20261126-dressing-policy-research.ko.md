# 시연 25·26으로 시작하는 50점 착의 정책 연구

*2026년 11월 26일 · PhyRC 2027 Phase 1*

[현재 시연 계획](../../README.md) · [시연 분석과 영상](../gallery/README.md#시연-분석) · [실행 순서](#실행-순서와-병행-일정) · [연구 레퍼런스](#연구-레퍼런스)

**우선 경로는 검토한 구간으로 π0.5 LoRA를 BC 학습하고, 검증한 중간 상태부터 잔차 RL로 목·어깨 조작을 보강하는 것입니다.** 새 시연에서 목과 어깨를 계속 시도하면서 원본 검증, 구간 라벨링, 기존 정책 패키지 점검을 시작할 수 있습니다. 최종 목표는 주최 측의 무작위 초기화부터 **50/50점과 `success=true`**를 재현하는 것입니다.

시연 25·26 HDF5에는 각각 전수 기술 QC 통과 기록이 있습니다. 먼저 시연 25는 고정 리비전의 백업과 해시를 확인하고, 시연 26은 수집 서버의 종료 원본과 슬롯 보존 위치를 확인합니다. 두 시연의 새 행동은 합계 **1,605전이(시뮬레이션 80.25초)**이며, 검토한 유효 동작만 골라내면 학습 분량은 더 적습니다. 이 데이터로 먼저 배울 대상은 파지, 지지, 천 이동입니다. ### 구간과 분할

- 공개 RGB-D로 좌우 각각의 `손목까지 걸침`, `팔꿈치까지 덮임`, `해당 소매 밖으로 손목·손끝이 나옴`을 따로 기록합니다. 목둘레와 몸통 밑단, 양쪽 어깨와 앞면 방향도 분리합니다. 가림은 `미확인`으로 남기고 표시 순서 R1·R0와 데이터 행 순서 R0·R1을 구분합니다.
- 성공·실패·미확인 라벨과 행동 승인 여부를 함께 기록합니다. 각 구간에 원본 run ID, 원본 해시, 시작·끝 전이, 부모 계보, 관측 근거, 실행 설정을 남깁니다. 정체·미끄러짐 자체는 실패 분석과 교정 요청에 쓰고, 실패에서 회복한 실제 행동은 별도로 승인할 수 있습니다.
- 시연 26 앞 2,346전이는 시연 25에서 재생한 행동입니다. 원본 행동 범위를 기준으로 중복 샘플링을 막고, 관측과 행동은 각각 기록된 실행 안에서 짝을 유지합니다. 시연 25–29처럼 부모가 연결된 계보는 같은 분할에 묶습니다. 새 초기 배치의 독립 시연을 검증용으로 확보할 때까지 같은 계보의 실험은 개발 결과로 기록합니다. [수집·QC 절차](collection.md#마감과-데이터-확인) · [데이터 가이드](../competition/DATA.md)

## BC·IL·RSI·RL 적용 순서

| 단계 | 구현할 내용 | 다음 단계로 넘어가는 기준 |
| --- | --- | --- |
| 1. 구간 BC | [기존 π0.5 로더](../../participant/pi05/data.py)는 `approved_pipeline_test`만 허용하고 에피소드 전체를 샘플링합니다. 실데이터 검토·승인을 별도 추가하고 승인 구간 안에서만 10전이 행동 청크를 구성합니다. 종료·재생 경계를 넘는 청크를 제외하고 정규화 통계는 학습 분할에서만 계산합니다. [JAX LoRA trainer](../../participant/pi05/train.py)를 재사용합니다. | HDF5와 라벨 전이 정렬, `(2,9)` 행동 범위, 독립 분할을 확인합니다. 학습 손실과 함께 실제 정책을 짧게 실행해 지지 유지와 천 이동을 확인합니다. 같은 데이터로 가벼운 비교가 필요하면 ACT를 추가합니다. |
| 2. 구간 초기화 RSI | **Reference State Initialization**은 시연의 중간 상태에서 학습 에피소드를 시작하는 방법입니다. 먼저 집게가 천을 지지하고 목둘레에 접근 가능한 슬롯을 시험합니다. 원본 영상과 복원·정착 후의 공개 영상/로봇 자세를 비교하고, 같은 짧은 공개 행동을 여러 번 실행해 파지 유지와 다음 상태를 확인합니다. 실패 원인도 기록합니다. | 시연 25 종료점과 시연 26의 2,346전이에서 집게 높이가 R0·R1 각각 19.6cm·13.8cm 차이 났습니다. 전이 번호 대신 복원 뒤 장면과 행동 결과로 같은 단계인지 판정합니다. 확인된 슬롯을 모아 목·어깨 인접 상태에서 시작하고, 성공이 생기면 이른 상태와 무작위 초기화까지 넓힙니다. [복원 근거](20261126-demo25-27-analysis.ko.md) · [시뮬레이터 초기화·평가 콜백](../../src/PhyRC_Sim/Policy/environment.py) |
| 3. 잔차 RL | BC를 고정하고 제한된 크기의 행동 보정 `clip(a_BC + β × Δa, -1, 1)`을 시험합니다. 기존 환경의 `evaluator` 훅에 훈련 보상과 종료를 연결하고, 슬롯 선택과 잔차 학습 루프를 구현합니다. 소매 통과·목 통과·어깨 접근에 단계 보상을 주고, 파지 손실이나 이미 달성한 착의 상태 이탈을 보상에 반영합니다. | 같은 복원 상태에서 잔차 0인 BC와 비교해 공식 항목 추가 득점과 단계 유지가 반복되는지 확인합니다. 이후 더 이른 슬롯과 공식 무작위 연습 시드에서도 비교합니다. 수집 속도와 복원 성공률을 실측한 뒤 학습량을 늘립니다. |
| 4. 교정 IL과 반복 개선 | **Recursive Self-Improvement**는 실패 영상을 검토하고 지시·관측·복구 동작을 한 가지씩 고친 뒤 다시 검증하는 과정입니다. 공개 관측만 본 사람 또는 기존 수집 에이전트가 실제로 실행해 회복한 행동을 다음 IL 데이터에 추가합니다. HiPhys-RSI의 절차 개선, RoboRSI의 절차·학생 정책 반복 갱신을 참고합니다. | 같은 시작 상태, 관측, 행동 예산으로 수정 전후를 비교합니다. 새 목·어깨 시연이 확보되면 먼저 성공 구간을 승인해 BC에 넣고, 잔차 RL은 반복해 막히는 조작에 집중합니다. |

공식 규정은 훈련 환경 내부 상태의 사용 범위를 **보상·종료·리셋**으로 제한합니다. actor, critic, 교사와 영상 검토의 입력은 공개 관측으로 구성하고, 내부 기하나 평가 로그로 행동·교사 목표를 만들지 않습니다. 기존 GPT 수집의 입력 접근 범위와 사람 개입 이력을 문서화하고, 자동 수집의 규정 적용에 해석이 남으면 주최 측에 질의합니다. 훈련 슬롯과 원본 재생은 개발·훈련 환경에서 사용하고 공식 평가는 주최 측 무작위 초기화에서 정책만 실행합니다. [공식 규정](../competition/RULES.md)

비교는 `현재 π0.5 → 구간 BC → 구간 BC + 초기화 RSI·잔차 RL → 교정 IL 추가` 순서로 합니다. 공통 슬롯과 독립 연습 시드를 나눠 같은 후보끼리 비교하고, 시드별 유효성·원점수·각 채점 항목·`success`·sim 시간·실제 경과·VRAM을 기록합니다. 가까운 테이블과 마찰 0.35는 현재 수집 설정으로 기록하고, 공식 일반화 검증에서는 주최 측 랜덤화를 그대로 사용합니다.

**50점 확인 기준.** 픽업 5점, 첫 소매 5점, 반대쪽 어깨 5점, 둘째 소매 5점, 양 위팔 각 5점, 목 10점, 앞면 방향 10점을 확인합니다. 손목·팔꿈치까지 천이 덮인 영상은 구간 진전으로 기록합니다. 소매 배점은 대응 소매 밖 손목과 손끝을 확인하며, `success`는 서로 다른 소매 밖의 두 손, 목 통과, 올바른 앞면이 동시에 0.5초 유지되어야 합니다. 누적 50점과 `success`를 함께 보고합니다. [공식 배점과 성공 판정](../competition/EVALUATION.md)

## 실행 순서와 병행 일정

| 작업 창 | 할 일 | 산출물과 결정 |
