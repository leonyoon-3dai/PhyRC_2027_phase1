## 지금 전략에 남긴 근거

짧은 lift 명령 뒤에도 실제 높이 변화가 이어져 명령과 파지점 운동을 분리해서 보아야 했다. 몸쪽 접근을 계속하면서 손의 화면 위치가 옮겨졌지만 그리퍼·옷 경계 뒤 가림도 커졌다. 사용자가 가림을 검토해 추가 접근했으나 실제 입구 진입·소매 통과는 확인하지 못했다.

마지막117→120전이에서는 같은 평면 명령에도 R0/R1 grasp worldY 변화가+5.31/+0.26mm로 달라졌다. R1 베이스는 계속 움직였고 명령0인 yaw·arm 관절도 변했다. 사용자는 왼손 쪽 충돌을 의심했으며, 공개 상태만으로 접촉·끼임 등 원인을 확정하지는 않았다. 후속 검토에서 어깨–팔–손 연결로 확인한 매핑은 **R0=오른손 쪽, R1=왼손 쪽**이다. 카메라 이름이나 화면 위치만으로 해부학적 좌우를 정하지 않는다.
