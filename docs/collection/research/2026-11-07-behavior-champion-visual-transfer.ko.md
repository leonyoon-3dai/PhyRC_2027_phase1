**우선 참고할 것은 큰 모델이나 반복 횟수 자체보다, 관측으로 검증한 절차와 복구 조건을 축적하는 방식이다.** 사용자 요청으로 텍스트와 그림·선택 영상 프레임을 함께 검토했다. 아래의 PhyRC 적용은 우리 가설이며, 외부 방법을 설치하거나 현재 E20의 실행 코드를 변경하지 않았다.

## 다음 시연 수집에 연결할 가설

아래는 외부 결과를 그대로 가져오는 지침이 아니라 우리 환경에서 따로 검증할 설계다.

| 우선 후보 | 현재 기록과 연결 | 실제 비교에서 확인할 것 |
|---|---|---|
| **지지와 순서부터 변경** | E19는 공중에서 같은 두 파지를 유지해 세 번 접근한 뒤 종료했다. E20은 기존 테이블 지지 아래 다른 위치로 파지를 옮기는 중이다. | 새 파지 위치·옷의 국소 동행·입구와 몸판 연결이 실제로 달라졌는지 본다. 테이블을 쓴다고 자동으로 입구가 열리는 것은 아니다. 외부 사례의 상자 등 새 물체를 장면에 추가하지 않는다. |
| **공식 시연의 넓은 몸통 입구·머리 위 접근 비교** | 공식 영상은 넓은 가까운 가장자리 지지→머리·팔 위 올림→하강의 흐름을 더 직접 지지한다. 목선을 먼저 다시 잡는 E20과는 다른 가설이다. | 현재 관측에서 몸통 입구·머리·팔 여유가 보일 때만 단계적으로 비교한다. 이전 실행의 정답 위치나 자유 시점 영상을 actor에 주지 않는다. |
| **행동 전후 조건이 있는 짧은 절차** | E19 D7은 그리퍼 기준점 세계 이동3.774mm·회전11.216°였지만 D8은41.423mm 움직였다. 같은 ‘위치 보상’ 설명도 실제 결과가 달랐다. | 상태·시야·지지 전제, 최대 동작 범위, 다음 관측에서 필요한 변화, 불충족 시 복구를 붙인다. 고정 행동 궤적을 성공 정책처럼 재생하지 않는다. |
| **실패 유형별 후속 선택** | E18 축 표현 오류는 named로 다뤘고, E19는 실제 운동이 있었는데도 손–입구 관계가 풀리지 않았다. | 명령 오류·미완료 운동·시야 가림·옷 형상·입구 연결 미확인을 서로 다른 문제로 분류한다. 점수 하나로 파지 실패를 정답화하지 않는다. |
| **검토된 부분동작만 후보로 축적** | 오류·복구도 학습 검토 자료로 보존해 달라는 사용자 요청과 연결한다. | 절차 버전·출처 그룹·관측/행동 경계·성공한 하위 목적·미확인 과제 결과를 함께 보존한다. unreviewed 원본을 자동으로 모방학습 승인하지 않는다. |

현재보다 추가되는 핵심은 사후 서술을 다시 읽는 데 그치지 않고, **공개 관측으로 확인 가능한 시작·진행·복구 조건을 가진 작은 절차 카드**로 바꾸는 것이다. 첫 후보는 지지 유지하의 시야 변경처럼 범위가 좁은 동작이 적합하다. 실제 제어에 넣기 전 닫힌 기록에서 잘못된 상태 전환을 점검하고, 한 가지 기능만 비교한다. 전체 파이프라인을 한 번에 도입하거나 학습을 시작하는 계획은 아니다.

조건을 선택하는 actor에는 공개 관측과 허용 로봇 상태만 준다. 과거 점수·평가 판정이 포함된 연구용 능력 카드를 actor 입력으로 연결하지 않는다. BEHAVIOR 성과 수치·훈련 정보 허용 범위가 PhyRC에도 그대로 적용되는 것은 아니다.

## 이번 조사로 완료한 것

텍스트와 공식 공개 집계를 교차 확인했고, 주요 도표·선택 영상 프레임의 직접 관찰과 문구의 한계를 기록했다. 자료에는 조회일·원본 SHA·선택 시각이 있다. E20 실험은 별도로 계속되며, 새 제어 절차·VLA 학습·외부 코드 설치는 아직 수행하지 않았다. 실제 도입 여부와 효과는 후속 시도에서 따로 기록한다.
