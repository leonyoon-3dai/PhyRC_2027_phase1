# E29 이후: 결정을 더 주는 것의 효용

**E29는 추가 20판단을 모두 쓰지 않았다. 10개 실제 행동 후 11번째 판단에서 actor가 종료했다.** 따라서 이번 결과는 “20번으로도 시간이 모자랐다”는 근거가 아니다. 현재 공개 관측만으로는 **같은 접근에 예산만 더 늘리는 것보다, 비교할 조작 가설을 명확히 바꾸는 편**이 더 타당하다. 새로운 시도나 예산 변경은 사용자 판단으로 남긴다. ## 추가 판단이 제공한 것

| 새 판단 범위 | 공개 관측의 효용 | 남은 문제 |
|---|---|---|
| 처음 5개 / 경계 784 | 한쪽 낮춤, roll, 반대쪽 yaw로 새로운 입구 방향을 시험. 양측 국소 지지·같은 손 근처 관계 유지 | 손가락이 경계를 지났다는 증거는 추가되지 않음 |
| 다음 5개 / 경계 834 | 전진 뒤 가림, housing 회피, 올림·거두기 뒤 입구 축소, 복구를 관측. 다음 비교의 실패 원인 후보를 좁힘 | 입구가 더 좋아졌다고 보기 어렵고, 새 착의 이정표도 미확인 |
| 11번째 판단 | actor가 현재 시도의 생산성이 낮다고 판단해 종료 | 가능한 모든 조작이 없다는 증명은 아님. 후속 정책·방법 비교 여지는 남음 |

총 834전이는 738 replay + 42 새 행동 + 54 정착으로, 새 물리 구간은 4.8초다. 실제 경과는 약 **26분 11.5초**, 12회 actor 호출 집계는 **12분 55.8초**였다. 전자는 prefix 재실행을 포함하고, 후자는 공개 입력 준비·Docker/CLI 시작·요청/응답을 포함하므로 모델 내부 추론 시간과 같지 않다. 모델 대기는 물리를 진행시키지 않는다.

전수 QC는 **834/834 통과·오류 0**이다. 별도의 유효한 로컬 공식 평가는 **5/50·새 구간 득점 0·착의 0·success=false**로, pickup 5점은 재실행 구간 경계 371에서 얻었다. 따라서 추가 판단에는 실패 원인을 비교할 정보의 가치가 있었지만, 시간 비용에 대응하는 새 착의 점수는 없었다. 백업 검증은 마감 receipt를 따르며 학습 승인은 `unreviewed`다.

E29는 새 actor와 정확히 같지 않은 물리 재실행으로 시작했다. 시작 공개 관측은 E28/738과 가까웠지만, 이 비교를 **추가 예산만 바꾼 인과 실험**으로 볼 수 없다. 처음 5개의 새로운 조작이나 마지막 정체를 전부 예산 증가의 효과로 설명하지 않는다.

## 다음에 바꿀 가설

기본 비교 출발점은 **E28 / 738**이다. E29 / 784는 이미 바뀐 입구 방향을 유지할 때의 대안이며, 최종 834는 좁아진 입구를 보존하므로 기본값으로 올리지 않는다. 첫 진입 전 비교가 필요하면 E28 / 682를 사용할 수 있다.

사용자의 [아래로 낮추고 대각선으로 돌려 올리는 제안](2026-11-13-user-diagonal-entry-feedback.ko.md)을 시험한다면, **같은 손의 연결 전완을 유지하면서** 낮춤 → 방향 변경 → 조건부 올림을 각각 관측한다. 한쪽 유용한 지지는 유지하고, 움직이는 쪽의 로봇·방향·크기는 현재 공개 관측에서 선택한다. E29의 올림은 거두기·다른 손으로의 전환이 섞였으므로 이 제안의 분리된 시험이 아니었다.

기록할 대안 가설은 두 가지다. 접힌 입구 자체가 문제인지, 그리퍼·잡은 모서리 쪽으로 접근해 통로가 가려지는지 구분한다. 방향 변경 뒤 **경계의 상대 이동과 손–그리퍼 여유를 함께 비교**한다. 색 띠·투영 겹침·손가락 가림으로 입구 정체·충돌·통과를 인증하지 않는다.

## 이후 새 시연마다 검토할 기준

같은 방식의 추가 예산은, 종료 직전까지 유용한 지지가 유지되며 **새로운 손–경계 관계나 실제 진입 방향의 진행**이 계속되고 예산 때문에 끊겼을 때 근거가 강하다. 실제 로봇 운동이 있었어도 같은 가림·접힘만 반복되거나 복구로 이전 관계를 되찾는 데 그쳤다면, 시간이 더 들기 전에 방법 변경의 근거를 검토한다. 모델의 `progressing`·`blocked` 표시는 관측과 함께 확인할 판단이며 자동 결론이 아니다.

다음 보고에서도 승인 예산, 실제 act 수, 종료 이유, 새 물리 전이, 모델 호출·실제 시간, 지지 유지와 손 관계 변화, 별도 공식 점수를 나눠 기록한다. 부분 진전을 인정하면서도 새 점수가 없는 상태를 50점에 가까워진 확정 성과로 표현하지 않는다. 이번 문서에서는 실행 코드·프롬프트를 바꾸거나 새 수집을 시작하지 않았다.
