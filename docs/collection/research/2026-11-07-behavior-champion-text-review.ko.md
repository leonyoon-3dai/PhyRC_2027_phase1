## PhyRC에 옮길 구체적 가설 — 아래는 우리 설계 제안

| 현재 확인된 문제 | 제안하는 추가 기록·절차 | 검증할 차이 |
|---|---|---|
| 설명이 올바르고 명령이 유효해도 실제 운동은 다를 수 있다. | `요청 명령 → 실제 로봇 이동 → 천의 시각 변화 → 과제 관계`를 각각 기록한다. 세계 그리퍼 기준점·회전·목표 잔차를 함께 본다. | 실행됐다는 사실과 예상한 물리적 결과를 분리할 수 있는가. |
| 긴 전략 문장이 매 판단마다 같은 미확인을 되풀이할 수 있다. | 상태 카드에 현재 관측 경계, 확인한 관계, 미확인 관계, 다음 행동 목적, 진행 조건, 실패 시 복구 후보를 짧게 남긴다. | 새로운 근거 없이 같은 접근을 반복하는 횟수를 줄이는가. |
| 복귀나 중립 명령을 정착으로 취급하면 다음 관측을 잘못 비교한다. | 실제 변위·속도·목표 잔차를 비교하고, 관측이 더 필요한 경우와 목표 추종만 남은 경우를 구분한다. 정착 기준은 측정 후 정하며 고정 6전이를 수렴 증명으로 쓰지 않는다. | 호출 감소와 관측 손실 사이의 균형을 평가할 수 있는가. |
| 재사용 가능한 성공 절차가 아직 충분하지 않다. | 우선 작은 절차 하나만 후보 카드로 만든다. 예: 지지 유지하에 시야를 바꾸고, 실제 위치 변화와 옷의 동행을 재관측하는 절차. 시작 조건·이동 한도·복구 종료·실패 사례를 명시한다. | 새 시도에서 조건이 맞을 때만 재사용하며, 조건이 다르면 거부하거나 다시 관측하는가. |
| 기술 QC와 학습 승인은 다르다. | 카드에 `unreviewed / 검토한 부분동작 / 과제 성공 확인`을 분리하고 실패·복구 원본 경계를 붙인다. | 점수 없는 조작이나 오류 뒤 복구가 자동으로 성공 교사 행동에 섞이지 않는가. |

예를 들어 [E19 공개 운동 분석](../reviews/20261107-astra-entry801-named-001-motion.ko.md)의 D7에서는 robot0 세계 그리퍼 기준점이 **3.774mm 이동하고 11.216° 회전**했다. 운동 명령이 0인 robot1도 **5.280mm** 움직였다. 따라서 “한쪽을 고정하고 시야만 변경”이라는 문장을 실제 고정의 증거로 쓸 수 없다. 그리퍼 기준점은 천 접촉점의 정답도 아니다. named action은 축 표현을 명확히 했지만 이런 물리적 사후조건까지 보증하지 않는다.

상태 카드의 첫 후보는 아래 정도면 충분하다. 이 형식은 아직 actor에 적용하지 않았다.

```text
관측: run / boundary / 사용한 공개 카메라·로봇 상태
현재 근거: 영상에서 보이는 천의 동행, 실제 로봇 이동·잔차
미확인: 내부 입구 연속성, 접촉/하중 지지, 통과 여부
의도: 이번 행동으로 바꾸려는 관계 하나
진행 조건: 다음 공개 관측에서 확인할 변화
복구 조건: 변화 없음 / 가림 증가 / 지지 근거 소실 시의 별도 후보
출처·검토: source group / 절차 버전 / unreviewed 여부
```

이 카드로 닫힌 시도에서 먼저 누락·잘못된 상태 전환을 점검하고, 이후 한 가지 절차만 실제 비교하는 것이 좁은 도입 후보다. 규칙·입력·물리·20Hz 기록을 유지하면서 관련 진전, 반복 횟수, 실제 이동, 실패 후 복구, 모델 호출·실제 경과 시간을 함께 비교한다. 같은 E07 계열 prefix 재실행은 독립 검증 표본이나 동일한 천 상태 복원이 아니다. 비교는 새 관측에서 시작 조건이 맞는지 다시 확인해야 한다.

코드를 개선하는 개발 단계와 실제 actor 실행은 계속 분리한다. 실행 중 모델에 호스트 저장소·평가·내부 기하를 열어주거나 코드를 고치게 하는 제안이 아니다. 재사용 절차도 공개 RGB-D와 허용 로봇 상태만 소비하도록 검토해야 한다. 점수는 별도 마감 평가로 남기고 파지·입구·진입을 증명하는 정책 입력으로 변환하지 않는다.

## 영상과 문구를 섞지 않는 검토 기준

root의 별도 직접 시각 검토에서는 [case74 영상](https://behavior1k-champion.com/assets/vid/case74.mp4)의 선택 프레임 0/4/8/14초에 의자 운반이 보였고, 사이트 문구는 wheelbarrow 전면 파지로 설명했다. 이 문서 작성자는 그 프레임을 직접 판독하지 않았으며 해당 관측은 협업 검토 결과로 기록한다. 문구를 영상의 확인 사실로 옮기지 않는다. 전체 성공·접촉점·일반화는 짧은 선택 프레임만으로 확정할 수 없다.

우리 영상 검토에서도 행동 직전·후의 실제 관계와 불확실성을 붙여야 한다. 실패 비율 도표의 분모·중복 라벨이 확인되지 않으면 독립 실패 확률이나 실패 소멸로 해석하지 않는다. [E18 오류·복구 구간 기록](../reviews/20261106-astra-guide470-depth-001-learning-segments.json)처럼 오류와 복구를 보존하되, 학습 승인과 구분하는 현재 원칙을 유지한다.

이번 조사로 설치·외부 코드 실행·훈련·기능 도입은 하지 않았다. 확인한 리더보드 코드는 표시와 집계의 출처이며 HiPhys-RSI 구현이 아니다. 원문은 재배포하지 않고 URL·조회 시각·내용 해시를 남겼다.
