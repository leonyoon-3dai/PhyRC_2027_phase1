# 공개 관측으로 검토하는 절차·복구 카드 초안

**E16–E20의 닫힌 공개 기록에 적용한 사후 분석 초안이다. 실행 절차·성공 정책·훈련 승인본이 아니다.** BEHAVIOR 검토에서 참고한 “시작 조건과 복구 조건을 가진 짧은 절차”를 우리 기록에 연결한다. 외부 우승 방법의 코드를 이식하거나 성능을 재현했다는 뜻이 아니다. [텍스트 검토](2026-11-07-behavior-champion-text-review.ko.md) · [그림·영상 검토](2026-11-07-behavior-champion-visual-transfer.ko.md)

E21 실행 중 작성했으며 E21 관측·결과를 분석하지 않았다. 현재 actor의 프롬프트·도구·코드·규칙을 변경하지 않았다. 아래 수치와 횟수는 **과거 구간의 측정값**이며 새 행동의 좌표·목표 높이·자동 통과 기준이 아니다. 점수·과거 성공 라벨·외부 자유 시점 영상을 actor 입력이나 교사 행동 정답으로 연결하지 않는다.

## 카드의 공통 해석

각 카드에서 **공개 전제 → 실제 조작 → 실측 로봇 운동 → 천의 시각 관계 → 과제 관계 → 복구·불확실성**을 각각 기록한다. 앞 항목이 확인돼도 뒤 항목을 자동 승인하지 않는다. 로봇 실측과 천·입구의 시각적 가설은 다른 근거다. `확인한 관측`, `시각적 근거 있음`, `미확인`, `관측되지 않음`, `아직 시험하지 않음`을 구분하며, 가림 때문에 안 보인 것을 물리적으로 없다는 라벨로 바꾸지 않는다.

`grasp_pose_base`는 공개 **그리퍼 기준점**이지 천 파지점의 정답이 아니다. 손끝 원점 거리는 접촉면 간격이 아니며, close intent·낮은 속도·작은 목표 잔차만으로 파지를 확정하지 않는다. world/base/관절 좌표, 모델 행동과 뒤의 settle, 움직이지 말라는 명령과 실제 정지를 구분한다.

## 카드 C2 · 한쪽 국소 지지 시험

| 연결 항목 | 공개 증거와 향후 비교 조건 |
|---|---|
| 전제 | 몸판의 테이블 지지나 유용한 partner 지지가 보이고, 시험할 그리퍼와 인접 천을 현재 지정뷰에서 비교할 수 있다. 닫힘·잔류 운동의 불확실성을 C1에서 넘겨받는다. |
| 실제 조작 | E16 D21–23은 재파지한 robot0의 lift→hold→return. E20 D10은 robot0만 lift한 뒤 관측했고, 별도 hold/return 없이 D11에서 partner를 열었다. 두 절차의 증거 강도를 같게 취급하지 않는다. |

| 과제 관계 | 국소 지지 근거가 있어도 입구의 연결·정체는 남는다. E20 D19 양측 동시 lift는 robot1의 독립 시험으로 분류하지 않는다. |
| 복구·불확실성 | partner도 실제로 움직였는지 함께 확인한다. 국소 천이 가려지거나 자세 변화가 시험을 혼입하면 시야·지지를 회복한다. E16 D24–27처럼 낮은 복귀 중 자세가 달라지면 정확한 옛 높이 복귀를 필수로 강제하지 않는다. |

## 카드 C3 · 다른 경계로 실제 재파지했는지 확인

| 연결 항목 | 공개 증거와 향후 비교 조건 |
|---|---|
| 전제 | 현재 몸판의 테이블 지지 또는 해당 전략이 요구하는 유용한 partner 지지가 확인되고, 기존 경계와 별도로 접근 가능한 후보가 보인다. 새 파지 내내 필요한 지지를 유지할 수 있어야 한다. |
| 실제 조작 | 한쪽 release→현재 보이는 후보로 이동→close→C1/C2 재관측. E16 D12–20은 같은 오른쪽 가장자리 회복, E17 D4–8은 다른 lower-rim 후보를 겨냥한 재파지, E20은 두 로봇이 순차로 기존 밑단에서 먼 목 후보 쪽으로 이동했다. |
| 실측 로봇 | open/close intent뿐 아니라 손가락·그리퍼 위치가 실제로 바뀌었는지 확인한다. E17 D5 robot0 세계 기준점 이동80.91mm는 실제 큰 배치 변화였지만 어느 천 층을 잡았는지 알려주지는 않는다. |
| 천 관계 | 닫기 전 후보와 jaw의 관계, 닫기 뒤 그 주변 천의 동행을 남긴다. E17은 다른 후보를 겨냥했어도 반대 입구 층 파지 확인은 못 했다. E20도 새 두 위치가 실제 목구멍의 마주 보는 자유 경계인지는 미확인이다. |
| 과제 관계 | `재파지 사이클 실행`과 `새 층/개구부 제어 성공`을 나눈다. 파지를 “guide”라고 부르는 설명만으로 위치 변경을 기록하지 않는다. E18·E19의 실제 가이드 재파지는0회였다. |
| 복구·불확실성 | 실패 시 사용 중인 전략의 한쪽 변경·배치 보정 범위 안에서 지지·시야를 회복한다. 횟수만 소진했다고 경계 가설 전체가 불가능하다고 결론내리지 않는다. 양쪽을 동시에 놓거나 과거 영상 위치를 현재 목표로 복사하는 절차로 만들지 않는다. |

근거: [E16 D12–20 /352–414](../reviews/20261106-astra-support264-002.ko.md), [E17 D4–8 /392–432](../reviews/20261106-astra-layer352-001.ko.md), [E20 두 재파지 /480–690](../reviews/20261107-astra-neckline470-named-001.ko.md). **방법 변경은 실제 배치·목표 개구·접근 순서의 변경으로 기록하고, 그 효과는 별도로 평가한다.**

E20의 목 후보는 실제로 접근·닫기를 수행했지만 자유 경계와 연결된 개구부를 읽기 어려웠던 사례다. 현재 후속 비교에서는 목선 재파지의 우선순위를 낮춘다. 이 카드는 목선 선택의 재채택을 권고하지 않으며, 다른 몸통 경계 후보도 그 위치 변경·국소 동행·입구 연결을 각각 확인해야 한다는 기록 형식이다.

## 카드 C4 · 지지를 유지하며 경계·입구를 다시 보기

| 연결 항목 | 공개 증거와 향후 비교 조건 |
|---|---|
| 전제 | 현재 유용한 지지가 있고, 어느 경계·가림을 더 보고 싶은지 말할 수 있다. 완성된 개구부 확인 전에도 작은 지지 유지 형태·시야 변경으로 정보를 얻을 수 있지만, 불명확한 통로로 운반·진입을 승인하는 것은 별개다. |
| 실제 조작 | E19 D7 상방 시점, D8 측면 시점; E20 D20 높이·간격 확대, D21 손목 pitch와 reach/높이 보상. 새 파지가 없는 경우 그 사실을 유지한다. |

| 천 관계 | E19 D7·8은 손·팔·rim의 새 시각 정보를 얻었다. E20 D20·21에서는 로봇 자세와 국소 들림이 바뀌어도 연결된 목 입구는 미확인으로 남았다. 기준점 간격을 천 입구 폭으로 쓰지 않는다. |
| 과제 관계 | `시야/형상 변화`, `경계 연결 근거 증가`, `통과`를 분리한다. 유효 depth는 보이는 표면 거리일 뿐 숨은 입구·층·통과 판정이 아니다. |
| 복구·불확실성 | 한 뷰의 가림만으로 자동 종료하지 말고 다른 CURRENT 지정뷰·최근 공개 관측·실측으로 같은 관계를 재확인하는 비교를 검토한다. 과거만으로 현재 여유를 승인하지 않는다. 전체 뷰에서도 경계·방향이 불명확하면 지지된 시야·접근을 회복한다. |

근거: [E19 D7–8 /878–900](../reviews/20261107-astra-entry801-named-001-motion.ko.md), [E20 D20–21 /690–712](../reviews/20261107-astra-neckline470-named-001-motion.ko.md). 실제 시야를 바꿔 새 정보를 얻는 미세보정은 가치가 있지만, 새 grasp set이나 완성된 통과로 이름을 바꾸지 않는다.

**관측 해석 주의:** 배경이나 빈 픽셀이 보이는 것은 입구의 필요조건이 아니다. 앞쪽 입구 너머에 뒤쪽 몸판이 보일 수도 있다. 따라서 E20의 “파란 천으로 채워져 보인다”는 관측만으로 입구 폐쇄를 확정하지 않으며, 열린 구멍이라고 승격하지도 않는다. 앞뒤 경계의 연결·겹침·국소 상대 운동과 다른 현재 지정뷰로 두 가설을 구분해야 한다. 경계 정체가 불명확한 상태를 그대로 보존하고, 열린 입구 가설만으로 진행 공간까지 확보됐다고 간주하거나 밀기를 허용하지 않는다. **E20에서 실제 입구가 열려 있었다는 주장은 아니다.**

현재 task 문자열의 읽기 검토에서는 “배경/빈 픽셀을 보여야 입구”라는 명시 조건을 찾지 못했다. 이번 목 우선·overhead 후보는 프롬프트 선택만 추가했고 자동 영상 판정기를 추가하지 않았다. E20의 `NECKLINE_TASK`와 활성 `OVERHEAD_TASK`는 현재 경계·연결·여유를 추적하도록 하지만, 뒤 몸판이 보일 수 있다는 해석은 명시하지 않는다. 과거 `SUPPORT_DIAGNOSTIC_TASK`의 `free space` 문구는 빈 배경을 요구한다고 좁게 읽힐 여지가 있으나 E20·E21 task에 붙지 않는다. 이 구분을 문서에만 남겼고 현재 prompt·코드를 수정하지 않았다. 공개 depth 안내도 invalid를 빈 공간으로 해석하지 않도록 이미 명시한다. | 천 관계 | 접근 뒤 손이 천에 가리고 복귀 뒤 다시 보였다. 가림을 입구 진입으로 확정하지 않는다. D7·8에서 얻은 새 관측 정보까지 동일 실패 반복으로 지우지 않는다. |
| 과제 관계 | 마지막 접근 뒤에도 연속 통과 근거는 없었다. **실제 접근 있음 / 통과 미확인 / 가이드 재파지 미시험**을 동시에 보존한다. 이 기록으로 B의 실제 새 가이드 파지 효과까지 부정하지 않는다. |
| 복구·포화 | 실행·관측을 거쳤는데 같은 관계만 남는다면 숫자만 바꾸는 반복을 멈추고, 현재 지지 아래 관측면·개구 방향·파지 배치 변경 또는 종료를 비교한다. 새로운 관련 관계가 보이면 보정을 계속할 수 있다. 2–3회는 검토 단서이며 자동 종료·성공·강제 밀기 횟수가 아니다. |

근거: [E19 시각·행동](../reviews/20261107-astra-entry801-named-001.ko.md), [실측 세 접근 /821–843·854–878·910–932](../reviews/20261107-astra-entry801-named-001-motion.ko.md). 복귀는 로봇·시야의 부분 회복이며 천 checkpoint 복원이나 실험 초기화가 아니다.

E19의 named 출력에서 설명 없는 roll이 재발하지 않은 것은 행동 표현의 검토 결과다. 같은 파지를 유지한 착의 접근을 새로운 천 조작 방법으로 바꾸는 근거는 아니다.
