# 지지 확인 다음 단계: 가시성용 들기와 소매 방향 가이드의 비교 후보

**E07–E16의 공개 관측·최종 행동을 검토한 후속 설계다. 아래 비교는 미실행이며 효과·착의 개선을 검증하지 않았다. 진행 중인 E17의 소스·프롬프트·입력은 변경하지 않았다.** 점수·평가 내부 판정·숨은 천/마네킹 기하를 행동 정답으로 사용하지 않는다.

권고는 두 가지다. **실제 파지 배치를 바꾸는 B(몸통 지지 + 소매 방향 가이드)를 구조적 다음 후보로 두고**, 지지 확인 뒤 짧게 들어 형태를 드러내는 방법은 **들기의 허용 조건을 비교하는 제한된 진단**으로 구분한다. 들어 올리기·중력·손목 회전이라는 말만으로 새로운 조작 방법이라고 세지 않는다.

추가 검토에서는 **첫 소매 대신 머리 통과를 먼저 다루는 세 번째 후보**도 정당화됐다. 공개 평가 조건은 첫 소매를 선행 조건으로 요구하지 않으며, 초기 공개 영상에는 목선 후보를 구별할 시각적 근거가 있다. 아래 목 우선 항목은 이 두 사실과 아직 해결하지 못한 실행 조건을 나눠 기록한다.

## 평평한 테이블 위에서 완성된 입구를 요구하면 교착하나

**가능한 가설이지만 확정 원인은 아니다.** E16은 몸판이 테이블 근처에 있는 동안 국소 동행을 확인한 뒤 입구 확인에 실패해 운반 없이 종료했다. 지지가 확인된 상태에서 허용되는 모든 움직임까지 이미 입구가 보여야 한다고 해석하면, 입구를 드러내기 위한 움직임 자체를 막는 순환 조건이 생길 수 있다.

그렇다고 “테이블 지지가 문제이므로 높이 들면 해결된다”는 근거도 없다. E07·E15는 더 크게 들고 매달리는 형태를 만들었지만 이후 입구·손 관계를 해결하지 못했다. E15에서는 더 높은 들기와 가림 증가가 함께 관측됐다. 또한 E16의 소규모 높이·간격 보정만으로 모든 펼침 방법이 소진됐다고 결론낼 수 없다.

따라서 다음 두 조건을 분리해 비교할 수 있다.

- **형태를 드러내는 작은 동작의 허용 조건:** 현재 파지의 국소 동행과 필요한 로봇 여유가 관측됨. 이때 입구의 정체는 아직 불확실할 수 있다.
- **운반·손 진입의 허용 조건:** 현재 입구 경계와 진행 공간을 추적할 수 있고, 두 지지가 유지되며, 접근 중 손·그리퍼 관계를 판단할 수 있음.

첫 조건을 만족한다고 두 번째를 자동 통과시키지 않는다. 들기 뒤 어두운 틈이 커지거나 손이 사라지는 것만으로 입구·통과를 승인하지 않는다.

## 후보 1 · B: 몸통 지지와 소매 방향 가이드로 실제 파지 배치 변경

**구조적 비교로 우선 권고한다.** 기존 `coordinated-support-guide` 코드가 있지만 실제 소매 방향 재파지와 성능은 아직 확인되지 않았다. 한쪽이 몸통을 지지하고 다른 쪽이 관측되는 측면 경계로 옮겨, 몸통 입구에서 대응 소매 후보까지의 연결을 더 잘 드러낼 수 있는지 시험한다.

| 설계 | 미실행 제안 |
|---|---|
| 출발 | E17 종료 분석에서 가이드 파지로 활용할 가시 경계가 드러났는지 먼저 확인. 그렇지 않으면 닫힌 E16의470경계처럼 국소 지지를 확인했던 준비 상태를 새 재실행해 현재 관측으로 다시 판단한다. 정확한 천 checkpoint라고 주장하지 않는다. |
| 바꿀 것 | 양쪽 밑단 모서리를 유지한 채 높이만 바꾸는 대신, **한쪽 실제 파지 위치와 역할을 변경**한다. 다른 로봇은 몸통 지지 역할을 맡는다. |
| 재파지 전제 | 현재 영상에서 유용한 partner 지지와 테이블 지지를 확보한다. 기존 B는 이 둘을 요구하며 A에 추가한 table-only 회복 예외는 B에 자동 적용되지 않는다. 출발 조건이 맞지 않으면 그 차이를 별도로 검토한다. |
| 짧은 예산 | 처음에는 새 판단 최대12회 안에서 준비·한쪽 재파지1회·짧은 위치 보정최대2회·국소 동행 확인을 비교한다. 관측상 유용한 경계가 없으면 억지로 정해진 부위를 잡지 않는다. |
| 진행 근거 | 새 파지의 국소 동행이 확인되고 몸통 입구와 측면 소매 후보의 연결이 이전보다 명확해짐. 파지 위치가 실제로 바뀌었는지 전후 사진으로 확인한다. |
| 전환 근거 | 새 파지 뒤에도 같은 접힘만 움직이거나, 연결 경로를 구별하지 못하거나, 하우징 가림이 증가함. 숫자 미세조정만 반복하지 않고 테이블 지지 아래 복구한다. |

목적은 **손의 몸통 입구 진입→대응 소매 출구** 경로를 다루는 것이다. 손을 바깥에서 cuff 안으로 밀어 넣는 동작을 같은 경로로 취급하지 않는다. 소매 후보의 위치나 로봇 역할은 현재 지정 카메라에서 선택하며 미리 정한 world 좌표·숨은 garment label을 주지 않는다.

## 후보 2 · 지지 확인 후 운반 없는 단계적 들기·형태 관측

**E07/E15와 다른 새 물리 방법이 아니라, 지지와 입구 확인의 순서를 분리하는 진단 비교다.** 기존 파지가 유용하지만 평평한 상태의 입구 의미만 불확실할 때 검토한다. E17에서 다른 파지 배치를 얻었다면 그 배치에서 시험하는 것이 같은 모서리를 다시 당기는 것보다 비교 가치가 크다.

| 설계 | 미실행 제안 |
|---|---|
| 유지할 조건 | 현재 관측에서 양측 국소 지지와 로봇 여유가 확인됨. 베이스 운반·손 접근·재파지는 이 짧은 진단에 섞지 않는다. |
| 바꿀 조건 | 입구가 이미 보여야 들 수 있다는 요구 대신, **입구를 드러내는 목적의 짧은 들기**를 허용한다. 입구 확인 전 운반은 계속 금지한다. |
| 행동 | 새 판단 최대8회, 작은 상승 구간최대3회. 매번 실제 높이 변화·잔류 운동과 천 형상·가림을 관측한다. 상승량은 현재 여유와 공개 행동 scale에서 선택하며 고정된 world 높이로 이동하지 않는다. 필요한 관측 대기는 이 예산 안에서 구분한다. |
| 계속할 근거 | 몸판이 더 매달리면서 서로 다른 경계와 그 사이 공간을 새 시점에서도 추적할 수 있음. 전체 천의 테이블 이탈 자체를 필수 성공 조건으로 두지 않는다. |
| 멈출 근거 | 같은 접힘만 높아지거나 팔 가림이 커짐, 국소 지지 상실, 예상 밖 관절·그리퍼 변화. 여유 있는 관측 상태로 복구하고 같은 파지에서 더 큰 lift만 반복하지 않는다. 정확히 낮은 옛 높이로 복귀하도록 강제하지 않는다. |
| 결과 해석 | 형태 관측 개선/동일/악화와 비용을 기록한다. 이 짧은 제한에서 불명확했다고 중력 펼침 전체를 불가능으로 결론내리지 않는다. |

이 비교에서 유효한 입구가 드러나면 이후 단계에서 그리퍼를 손의 진행 공간 밖에 두고 접근 방향을 결정한다. 입구가 계속 안 보이면 픽셀 depth 질의를 추가하는 것보다 새 파지 배치·관측면 변경을 먼저 검토한다. depth는 보이는 표면 사이 거리 모호함을 줄이는 별도 수단이다.

## 후보 3 · 목선 재파지 후 머리 통과를 먼저 다루기

**순서와 파지 목표를 바꾸는 미실행 구조 후보다.** [공개 평가 안내](../../competition/EVALUATION.md#score-items)는 목 항목을 가슴이 옷 안에 있고 머리·목이 목 입구로 나온 상태, 앞면 항목을 머리가 나온 상태에서 V넥이 앞을 향하는 0.5초 상태로 설명한다. 두 항목에 첫 소매 통과를 선행 조건으로 붙이지 않는다. [챌린지 설명](../../project/CHALLENGE_GUIDE.ko.md#2-50점은-어떻게-쌓이는가)도 득점 순서가 달라지거나 동시 득점할 수 있다고 명시한다. 따라서 **공개 계약상 첫 소매 없이 목/앞면 항목에 도달하는 경로를 배제할 이유가 없다.** 실제 이 배치에서 가능한지는 별도 조작 검증 대상이다. 점수 숫자나 평가 내부 조건을 actor의 좌표·접촉 정답으로 전달하지 않는다.

[E15 초기 robot0 head](../assets/20261106-opening-first-partial-review/obs00000-robot_0_head.png)와 [robot1 head](../assets/20261106-opening-first-partial-review/obs00000-robot_1_head.png)에는 평평한 몸판의 먼 쪽 중앙에 V형 경계가 보인다. 이는 가까운 밑단 후보와 구분되는 **목선 재파지 후보의 시각적 근거**다. 색만으로 구멍을 확정하거나 역사 영상의 위치를 현재 좌표로 사용하지 않는다. [E07 운반 뒤 overview](../assets/20261106-transport-waypoint/observation-00048-overview.png)와 [head](../assets/20261106-transport-waypoint/observation-00048-robot_1_head.png)는 머리·몸통과 위로 든 팔, 기존 운반 위치를 보여 준다. 팔을 피해 머리 위에 목 입구를 배치할 로봇 여유와 관측 가능성은 아직 검증하지 않았다.

기록된 E07·E10–E16의 최종 결정에서 목선 재파지·머리 먼저 통과를 목표로 한 행동은 확인하지 못했다. 기존 운반 뒤에는 손의 소매 진입을 다뤘고 E16은 테이블 준비에서 끝났다. 따라서 이 후보는 같은 밑단 파지를 더 크게 들어 올리는 반복과 구별된다. 기존 B는 여전히 몸통 입구→소매 출구를 지시하므로 B를 실행했다고 목 우선 정책을 비교한 것이 아니다.

제안은 현재 영상에서 목선 후보와 이어진 몸판을 다시 확인하고, 테이블 또는 확인된 파트너 지지를 유지하며 **한 번에 한 그리퍼만** 목선 가까운 가시 경계로 옮기는 것이다. 반대쪽도 바꿔야 하면 첫 새 지지를 확인한 뒤 순차로 다룬다. 새 배치에서 두 지지와 실제 목 입구 경계가 확인돼야 운반한다. 색 띠·접힘·목선 접촉·머리 가림만으로 통과를 인정하지 않는다.

이후 관측되는 머리·가슴과 의복의 연결을 따라, 머리가 몸통 입구를 통해 옷 안으로 들어가 목 입구로 나오고 몸판이 가슴을 감싸도록 유도한다. 머리가 외부에서 목 구멍 안으로 눌려 들어가는 반대 방향을 완성으로 취급하지 않는다. 팔과 머리 위 여유가 안 보이거나 입구를 충분히 제어할 수 없으면 먼저 배치·시야를 복구한다. 한쪽당 재파지 1회와 짧은 위치 보정 최대 2회로 초기 배치 비교를 제한하고, 같은 가림·접힘이 2–3회 실행·관측 뒤 유지되면 숫자만 계속 바꾸지 않는다. 실제 머리 통과가 진행되면 소매와 나머지 착의를 이어갈 수 있다. **목을 먼저 다룬다는 후보이며 목 통과·10점 달성·완전 착의는 아직 검증하지 않았다.**

## 다음 선택 기준과 기록

E17 종료 후 **다른 가시 경계를 실제로 잡았는지**, **그 배치의 두 국소 지지가 확인됐는지**, **입구 의미와 거리 중 무엇이 남았는지**를 분리한다. 실제 파지 변경 없이 같은 좁은 틈만 남았다면 B가 더 명확한 구조 변경이다. 새 파지는 생겼는데 테이블 근처에서 형태만 읽기 어렵다면 두 번째의 짧은 들기 비교가 적절하다. 이미 입구가 보인다면 두 후보를 의무적으로 반복하지 않고 손 진행 공간·접근 방향을 다듬는다.

각 시도는 부모/source group, 새 재실행 관측, 실제 파지 변경 구간, 전후 RGB·공개 로봇 변화, 새로 드러난 관계, 종료·방법 전환 이유, 호출/전이/시간을 남긴다. 닫힌 시도의 별도 평가는 결과 검토에만 사용하며 actor 입력이나 행동 정답에 넣지 않는다. 이 문서 작성에서는 새 모델·GPU 호출, E17 관측 조작, 수집 코드 변경을 수행하지 않았다.
