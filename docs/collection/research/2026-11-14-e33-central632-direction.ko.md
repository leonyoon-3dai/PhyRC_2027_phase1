# E33 방향 · 검증된 E28/632에서 중앙 구간 조절을 이어 본다

**현재는 사용자 요청으로 중지 상태이며 E33은 시작하지 않았다.** 아래 선택은 중지 전 준비한 비교 계획이다. 새 서버에서도 자동 실행하지 않고 명시적 재개를 기다린다. [클린 서버 인계](../../project/sessions/20261114-paused-clean-server-handoff.ko.md)

**다음 출발점은 E28/632, 새 replay history는 588·614다.** `coordinated-central-span-entry`와 최대 20판단을 유지한다. 사용자가 승인한 시연→분석→다음 시연 반복 안에서 선택한 계획이며, 아직 E33 실행 결과가 아니다. [E32 공개 검토](../reviews/20261113-astra-central380-001.ko.md)에서 확인한 형상·운반 진전과 수집 불완전 상태를 함께 반영했다. E32의 어떤 경계나 행동 prefix도 재실행 출처로 사용하지 않는다.

## 공개 출발점 비교

## 다음 관측에서 판별할 것

- **형상 조절:** 현재 잡은 양 끝 사이의 쓸 수 있는 폭·깊이·여유가 실제로 변하는지 head/wrist를 함께 비교한다. U형 외관이나 파란 면만으로 입구 topology를 확정하지 않는다.
- **손 정렬:** 연결 전완으로 같은 손을 추적하면서 잡은 모서리·jaw 대신 자유 구간으로 상대 위치가 바뀌는지 본다. 손이 가려졌다는 이유만으로 진입이나 실패로 단정하지 않는다.
- **조건부 진행:** 실제 손–경계 관계가 뒷받침되면 짧은 진입·같은 전완 방향의 진행을 비교한다. 위쪽 이동, 시점 변화, 천의 외부 접힘을 팔을 따른 진행과 구분한다.
- **예산 효용:** 같은 상태 반복인지 실제 새로운 형상·접근·복구인지 판단 구간별로 확인한다. 기본 20판단을 자동 확대하지 않고 마지막 상태의 유용성, 수집 완료·QC·백업을 확인한 뒤 다음 분기를 정한다.

이는 현재 중앙 전략의 목적을 평가하기 위한 검토 기준이다. 별도 peel/regrasp 방법, 실시간 피드백 기능, 카메라→세계 좌표 변환이나 새 제어 계약을 이번 계획에 추가한 것이 아니다. E31과 비교할 때는 시작점과 전략이 함께 달라지므로 단일 원인의 효과로 주장하지 않는다.
