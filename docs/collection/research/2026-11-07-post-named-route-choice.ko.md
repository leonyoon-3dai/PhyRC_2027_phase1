# 명명 출력 비교 뒤의 착의 경로 선택

**E19가 진행 중일 때 작성한 조건부 다음 비교안이다. E19 결과나 다음 실행 완료를 뜻하지 않는다.** E18의 지정 RGB·공개 로봇 상태·최종 운영 설명·depth 질의 결과와 E16/E18의 공개 적용 행동만 검토했다. 숨은 천·마네킹 기하, audit, 평가 내부 판정을 사용하지 않았고 코드·actor 입력을 바꾸거나 모델·GPU를 호출하지 않았다.

권고는 **E19에서 올바른 이름별 명령이 실제로 실행된 뒤에도 같은 손·rim 가림이나 접힘이 포화되면, E18의470경계에서 목 우선 전략을 비교하는 것**이다. E19에 새로운 손·입구 관계가 계속 나타나면 그 진전을 먼저 다듬는다. 명명 출력은 표현 오류 비교이며 그 자체를 새 천 조작 방법으로 세지 않는다.

## 목 우선과 실제 가이드 재파지 중 선택

| 후보 | 선택할 공개 근거 | 구체적으로 달라져야 하는 행동 | 제한·전환 |
|---|---|---|---|
| **목 우선: 다음 구조 비교의 기본 권고** | E19의 올바른 명령·관측에도 같은 손 가림/접힘이 남고, 테이블 출발 관측에서 목선 후보를 구별할 수 있음 | 테이블 지지를 유지하며 한쪽씩 목선 근처 가시 경계로 파지를 바꾸고, 머리의 몸통 진입→목 입구 출현과 가슴 안착을 먼저 다룸 | 기존 후보의 로봇당 파지 변경1회·배치 보정 최대2회. 목선 제어·두 지지·머리/팔 여유가 확인되지 않으면 운반을 강행하지 않음 |
| 실제 가이드 재파지: 더 구체적인 시각적 원인이 있을 때 | E19에서 몸통 입구와 대응 소매 경로는 보이지만 기존 그리퍼 위치가 손의 통로를 가리는 관계가 반복 확인됨 | 테이블 지지 아래 한쪽을 **다른 가시 측면/소매 방향 경계**로 옮기고, 기존 파지와 달라진 위치·국소 동행·손의 통로를 확인 | B의 한쪽 변경1회·보정 최대2회 범위. 다른 부위를 잡았는지 확인되지 않으면 “새 가이드 방법 실행”으로 세지 않음 |

목 우선을 기본 다음 비교로 권하는 이유는 현재 구현된 B가 유용한 기존 파지를 보존할 수 있어 E18에서 실제 새 파지를 시도하지 않았기 때문이다. **같은 B 이름으로 같은 출발 상태만 반복하면 실제 변경 없이 다시 운반할 수 있다.** 목 우선은 목표 개구와 첫 착의 대상을 바꾸는 이미 구현된 별도 전략이다. 이것이 더 높은 성공 확률을 입증한 것은 아니다. 반대로 E19가 구체적인 그리퍼 방해와 접근 가능한 가이드 경계를 드러낸다면 작은 실제 재파지가 그 원인을 더 직접적으로 시험한다. 가시 근거 없이 재파지를 강제하지 않는다.

포화 판단은 올바른 채널 값이 공개 실측 로봇 이동으로 이어졌는지부터 확인한다. 같은 관계를 시험한 짧은 보정·관측2–3회에 새로운 관계가 없을 때 방법 변경을 검토하며, 횟수만으로 강제 종료하지 않는다. 잔류 목표 추종, 실제 새 rim 정보, 오류 복구를 똑같은 실패 반복으로 세지 않는다. E19 진행 관측은 별도 담당자의 검토를 사용하며 이 문서에서는 지속 모니터링하지 않았다.

## 현재 목 우선 프롬프트 검토

[통합된 목 우선 후보](2026-11-06-neckline-first-candidate.ko.md)는 CURRENT 목선과 몸판 연결, V형 색 띠·접힘의 불확실성, 새 파지 중 몸판의 테이블 지지, 첫 새 지지 확인 후 반대쪽 변경, 두 지지와 추적 가능한 개구 확인 뒤 운반을 이미 명시한다. 개구가 완전히 읽히기 전에도 지지를 유지한 작은 형태·시야 변경을 허용한다. 이전 소매 우선/hem-route task를 붙이지 않고 실제 머리 통과·가슴 안착 뒤 전체 착의를 계속하도록 한다. **이번 공개 검토만으로 추가 문구 변경은 필요하지 않다.**

명명 출력은 다음 경로에서도 유지하고, depth 질의는 보이는 표면 사이 거리 모호함을 해결할 때만 사용한다. 머리 위상·가림·소매 연결은 depth 유효값으로 해결됐다고 주장하지 않는다. E16·E18·E19와 다음 분기는 공유 prefix를 가진 같은 계보의 rollout 비교이며 독립 성공 표본이나 별도 검증 출처로 세지 않는다.
