# DexGarmentLab에서 참고할 PhyRC 시연 판단

**2026-11-18 연구 메모.** 현재 파지에서 접근 경로를 조정할지, 천의 파지 위치부터 바꿀지 구분하기 위한 참고 자료다. 다음 사용자 재개 지시를 받으면 저장소의 실행 계획과 복원 절차를 따른다. [현재 실행 계획](../../COLLECTION_PLAN.md) · [클린 서버 복원](../../OPERATIONS.md)

## 다음 시연에서 확인할 순서

1. **출발 상태를 확인한다.** 마지막 R0 단독 접근 전의 **B/HOLD1·110전이** 슬롯은 저장 및 해시 확인을 완료했다. 실제 복원은 확인 전이다. 저장 당시, 복원 직후, 정착 후의 공개 5카메라와 로봇 상태에서 양쪽 파지, 양손, 천의 펼침과 처짐을 비교한다. [출발점·복원 식별자](../../COLLECTION_PLAN.md#1-다음-출발-후보와-검증) · [저장 당시 5카메라](../user-reviews/20261116-astra-right-hand-hold10-001/hold-0001/README.ko.md)
2. **두 로봇을 마네킹 왼손 쪽으로 함께 옮긴다.** 양쪽 파지 의도를 유지하고 로봇별로 짧은 입력을 적용한다. 각 실행 뒤에는 양쪽 파지점과 천이 어떻게 움직였는지, 양손이 자유 경계에 대해 어디에 놓였는지 본다. 왼손은 어깨·팔꿈치·손의 연결로 식별한다. [공동 이동과 양손 걸침 순서](../../COLLECTION_PLAN.md#2-두-로봇-공동-이동--양손-걸침)
3. **손 위에서 내려올 여유를 확인한다.** 손 위에 자유 경계가 있고 그리퍼 본체와의 여유가 보이면 짧게 내려 걸쳐 본다. 명령 직후와 정착 후 같은 손·천 경계를 다시 확인하고 양손 걸침을 판단한다. 초기 행동 길이 후보는 기존 계획의 2–4전이다. [명령 직후·정착 후 변화 읽기](2026-11-16-checkpoint-effect-feedback.ko.md#4-실행-효과-피드백-무엇이-달랐는지-기록한다)
4. **가림이나 지지 문제는 HOLD에서 검토한다.** 같은 경계의 공개 5카메라와 구간 GIF를 제시한다. 현재 파지를 유지한 교정으로 경계를 드러내기 어렵다면, 사용자 판단을 받아 한쪽 지지를 남긴 가운데 쪽 재파지를 별도 비교 후보로 둔다. 노란 표시를 따라 보이는 자유 구간이 길어지는지, 주름과 그리퍼 본체 가림이 줄어드는지 확인한 뒤 하강 여부를 판단한다. [사용자 검토 화면과 질문](../../COLLECTION_PLAN.md#4-사용자에게-보여-줄-화면과-질문)

| 짧은 행동 뒤 관측 | 기록할 내용 |
|---|---|
| 파지점은 움직였지만 손·자유 경계의 관계가 그대로다 | 양쪽 파지점의 실제 변위, 가시 경계와 그리퍼 본체 위치, 정착 후 변화 |
| 양손이 보이지만 천 경계가 가려진다 | 어느 카메라에서 무엇이 가렸는지와 `unknown`. 같은 공개 관측의 유효한 depth는 표면 위치 확인에 사용 |
| 정착 후 손목 위에 천이 유지된다 | 보이는 걸침과 양쪽 지지, 손끝·소매 출구의 관측 여부 |
| 공식 첫 소매 점수가 새로 오른다 | 평가에서 확인한 `first_sleeve`의 새 0→5점. 영상의 걸침 판단과 함께 별도 기록 |

## 논문에서 가져올 부분

| DexGarmentLab의 방법 | PhyRC에서 확인할 가설 |
|---|---|
| **GAM**은 시연에서 잡은 지점과 같은 구조적 역할을 하는 지점을 변형된 옷에서 찾는다. | 공개 RGB-D에서 현재 파지점, 가시 자유 경계, 마네킹 손목을 따로 표시한다. 노란 표시는 같은 천 구간을 추적하는 단서로 쓰고 개구부 후보는 여러 시점에서 확인한다. |
| **SADP**는 옷과 주변 대상의 형상·위치에 맞춰 조작 궤적을 생성한다. | 이동 거리가 비슷해도 손·천 관계가 다를 수 있다. 현재 관측을 바탕으로 접근 방향과 높이를 조정하고 정착 후 효과를 비교한다. |
| 논문의 한계 분석은 심한 주름과 가림이 지점 추정을 어렵게 하며 주요 부위를 먼저 드러내는 조작이 필요할 수 있음을 설명한다. | 손과 자유 경계 중 가려진 항목을 남긴다. 현재 파지에서 시야나 천 형상을 바꿔 보고 필요하면 가운데 쪽 재파지의 효과를 비교한다. |
| 전문가 시연에서 파지점·작업 순서·손 자세를 얻고, 새 옷의 형상에 맞춰 경로를 계산해 실제로 다시 실행한다. | 성공하거나 복구된 짧은 구간에서 파지 지점과 단계 순서를 기록한다. 새 공개 관측에 맞춘 행동을 실행하고 다시 검수해 시연 후보를 쌓는다. |

[논문 §4.1–4.2·그림 5·§5·부록 I.3](https://arxiv.org/html/2505.11032v3) · [프로젝트 영상](https://wayrise.github.io/DexGarmentLab/) · [공개 코드](https://github.com/wayrise/DexGarmentLab)

논문의 **상의 걸기** 시뮬레이션 성공률은 DP3 53%, GAM을 뺀 HALO 64%, 전체 HALO 92%였다. 이 결과는 해당 작업에서 조작 지점과 궤적 표현의 기여를 보여 준다. 실험은 고정형 UR10e와 ShadowHand를 사용했다. 장갑 착용은 부착 방식으로 시연했고 정책 평가에서 제외했다. 티셔츠 소매를 마네킹 팔에 통과시키는 성능은 검증 범위 밖이다. [논문 표 2·부록 I.2·K.15](https://arxiv.org/html/2505.11032v3)

PhyRC에서는 **지정 5개 RGB-D, 공개 로봇 상태, 기존 `(2,9)` action**을 사용한다. 논문의 GAM 학습은 시뮬레이터에서 옷의 점을 추적해 대응을 만들었다. 공식 천의 내부 입자나 메시를 이용한 목표점·행동 라벨 생성은 PhyRC 규칙에서 금지하며, 관측 가능한 표면과 사람의 공개 영상 검토를 근거로 삼는다. [PhyRC 관측·학습 규칙](../../competition/RULES.md)
