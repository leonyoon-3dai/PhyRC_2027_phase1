# 2026-11-13 Pro 요금제와 수집 속도

**Pro $100에서 $200로 변경하면 사용량 제한 때문에 멈추는 수집을 더 오래 이어가는 데 도움이 될 수 있다. 같은 Astra 호출 한 번의 응답이 자동으로 빨라진다는 보장은 확인되지 않았다.** 2026-11-13 공식 안내에서 Pro 200은 Pro 100보다 사용량이 많으며, 두 요금제 모두 Ultrafast를 포함하지 않는다. Pro 500에는 Ultrafast가 포함된다. 이는 요금제 비교이며 이 작업에서 구독·결제는 변경하지 않았다. [공식 Pro 요금제 안내](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers)

| 구분 | 이 저장소 수집에 대한 의미 |
|---|---|
| 사용량 여유 | 한도 소진으로 중단되는 상황이면 더 많은 호출·시도를 이어갈 여지가 생김. 완성 시연 수나 점수 상승을 보장하지 않음 |
| 호출 응답 시간 | 입력 크기·추론 설정·서비스 대기·실행 준비를 포함하는 실제 측정값으로 비교해야 함 |
| `ultra` 추론 수준 | 모델이 들이는 추론의 설정. **Ultrafast 속도 모드와 별개** |
| Fast / Ultrafast | 응답 속도 관련 선택지. 사용량 소모가 커지며 계정·모델의 지원 여부를 별도로 확인해야 함 |

공식 문서는 추론 수준을 모델 선택과 별도로 설명하며, Fast는 더 빠른 응답과 더 큰 사용량 소모를 제공한다고 안내한다. 따라서 $200 변경의 예상 이점은 우선 **지속 가능한 수집량**으로 해석한다. 현재 병목이 사용량 제한인지 단일 호출 대기인지 확인하지 않고 속도 배수를 추정하지 않는다. [Astra 사용량·추론·속도 안내](https://help.openai.com/en/articles/20001516-managing-usage-with-gpt-6-astra-in-work-and-codex)

현재 [`Actor._cli()`](../../../participant/collection/codex_actor.py)는 `--ignore-user-config`로 사용자 설정을 읽지 않고 명시한 `model_reasoning_effort`를 전달한다. 수집 설정은 `gpt-6-astra` / `ultra`이며, 이 함수는 `service_tier`를 지정하지 않는다. 사용자 설정 파일이나 앱의 속도 선택이 이 고정 CLI 경로에 자동 반영된다고 가정할 수 없다. 이번 확인에서는 actor 코드·추론 수준·속도 설정을 변경하지 않았다.

속도 비교가 필요하면 동일한 관측·전략·모델·추론 수준·행동 예산에서 모델 호출 경과와 환경 실행 경과를 분리해 측정한다. 모델 대기 중 물리는 멈추므로 20 Hz 기록 주기를 모델 응답 속도로 해석하지 않는다. **요금제 간 벤치마크나 호출 시간 개선 실험은 수행하지 않았다.**
