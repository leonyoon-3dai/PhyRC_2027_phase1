# 장기 계획 · 득점 구간의 조합과 합성 자료

사용자는 장기적으로 0→5→10처럼 점수가 올라가는 구간의 여러 방법을 조합해 자료를 늘리는 방향을 제안했다. 현재는 [출발점 목록](../catalog/README.ko.md)으로 실제 5→10 시도를 우선한다. **2026-11-07 E27 진행 중 기준 최고 공식 기록은 5점이며 10점은 미달성**이다. 아래는 기존 수집·검수 체계를 확장하는 계획으로, 새 합성 자료 생성이나 학습은 수행하지 않았다.

## 구간을 잇는 데 필요한 기록

| 기록 | 목적 |
|---|---|
| 원본 run·source group·소스 snapshot·직접 부모·행동 경계 | 원본 구간과 파생·재실행·합성 구간을 추적하고 중복 출처를 구분 |
| 시작/종료 공개 관측·파지 배치·입구 가설·로봇 목표와 실측 | 같은 점수여도 서로 다른 천·로봇 상태를 구별하고 연결 가능성을 검토 |
| 득점 전후의 공식 점수·항목·확인 경계 | 결과를 별도 선택·검수 자료로 기록. 점수 자체를 actor 입력이나 파지 정답으로 쓰지 않음 |
| 실제 수행 방법·관측 변화·실패·복구·미확인 조건 | 이름이 같은 전략의 서로 다른 실제 조작을 구별 |
| 연결 절차·재실행 검증·새 관측·변경한 행동 | 단순 파일 연결과 물리적으로 실행된 새 궤적을 구별 |
| 합성 방식·원본 기여 구간·검수/QC·학습 승인 | 합성 자료의 출처와 유효성, 실제 성공 여부를 재검토 |

0점·5점·10점은 완전한 상태 표현이 아니다. 예를 들어 같은5점이라도 테이블 근처의 옷, 높은 운반 자세, 손 근처의 가림 상태가 다를 수 있다. 따라서 점수만 같은 두 구간을 바로 이어 붙이지 않는다. 현재 파지·옷 형태·로봇 자세의 호환 가능성을 공개 관측으로 검토하고 실제 실행에서 연결부를 다시 확인해야 한다.

연결 경계에는 전이 범위 `[a,b)`와 끝 관측 `b`, 준비행동의 **의도한 길이와 실제 도달 길이**, 새 행동·자동 안정화·종료 정리 전이를 구분한다. 공개 로봇 자세·속도·목표 잔차, 각 로봇의 역할과 천의 국소 동행, 테이블 지지와 가림, 잡은 층·입구·의복 방향의 불확실성을 함께 비교한다. 호환 여부가 미확인이면 검증할 가설로 남긴다. 이는 모든 입구를 완전히 확인해야 움직일 수 있다는 actor 규칙이 아니며, 재실행에서 현재 공개 관측에 따라 접근·복구 가능성을 다시 판단한다. 과거 구간의 끝 관측을 새 실행의 현재 상태로 대신하지 않는다.

## 단계별 확장

1. **실제 구간 검색:** 현재 목록에서 양측 지지 근거와 원본 검증이 있는 출발점을 찾고, 같은 출발점에서 방법을 달리한 실제 분기를 수집한다.
2. **조합 후보 생성:** 앞 구간의 끝과 다음 구간의 시작에 필요한 관측 조건을 비교한다. 방법·입력·행동 표현과 미확인 조건을 명시한다. 점수 구간이 실제로 확인되기 전에는 해당 성공 구간이 있는 것으로 채우지 않는다.
3. **시뮬레이션 재검증:** 공식 물리·20Hz·정식 행동·공개 입력 경계에서 새 run으로 연결과 전체 결과를 검사한다. 행동 재실행은 정확한 천 checkpoint 복원이 아니므로 새 관측·행동을 기록하고, 연결을 위해 새로 수행한 보정과 실패도 보존한다. 종료된 전체 기록의 QC와 연결부 관측 검수, 새 실행의 공식 평가가 갖춰진 뒤에만 검증 범위에 맞는 결과를 붙인다. 원본의 최종 점수나 경계 점수를 새 실행에 복사하지 않는다.
4. **파생 자료 분류:** 단순 재배열·실제 재실행·새 정책이 연결부를 보정한 궤적을 구분한다. 관측되지 않은 중간 프레임·접촉·입구·성공 라벨을 만들어 붙이지 않는다.
5. **학습·평가 전 검토:** 원본과 재실행·선별 구간·모든 파생 조합을 계보 단위로 묶어 train/validation/test 누출을 막는다. 미래에 여러 출처를 조합하면 모든 기여 원본의 계보를 연결해 같은 분할에 둔다. 공유 prefix와 겹치는 클립을 독립 신규 시연으로 중복 집계하지 않고, 전체 기록량·새 전이량·출처 그룹 수를 나눠 보고한다. 기술 QC와 시각 검수·학습 승인을 분리하고 현재 `unreviewed` 자료를 자동 승인하지 않는다.

재사용할 수 있는 것은 관측에 근거한 절차와 검증된 사례이지, 점수에서 추정한 숨은 좌표나 접촉 정답이 아니다. 시연 부분 성공·회복·실패도 보존하되 전부 좋은 행동 모방 자료로 취급하지 않는다. 현재 SQLite는 원본 실행·출발점·방법·시도 관계를 검색하는 첫 단계이며, 미래의 구간 그래프·합성 연결부·훈련 자료 생성기는 아직 구현하지 않았다.

공식 총점과 항목별 변화는 사후 결과·선택 근거로 분리하고, 공개 관측상의 로봇 이동·천 지지·입구 후보·실제 통과를 각각 기록한다. 점수 정체만으로 모든 중간 기술을 실패로 표시하거나, 공개 시각 진전만으로 득점 성공을 부여하지 않는다. 실패·복구·잔류 운동을 기다린 구간도 목적을 명시해 보존하며, 질의의 물리 0전이와 미실행 응답은 행동 시연에서 구분한다. 사후 검토나 뒤 관측을 앞선 actor 입력에 섞지 않는다. 현재 카탈로그의 `review_ready`는 기술적인 원본 준비 상태이고, `tested`는 종료 시도와의 연결이며 학습 승인이나 방법 성공을 뜻하지 않는다([도구의 의미 범위](../catalog/TOOL_GUIDE.ko.md)).

[E23 실제 사례](2026-11-07-stage-composition-e23-case.ko.md)는 점수 정체와 관측 진전을 구분하고, 사후 관측을 이전 입력에 섞는 누수 및1179/1180 접합 경계 혼동을 구체적으로 기록합니다.

### E24 후속 사례 · 점수 유지와 시야 복구를 구분

[E24 검토](../reviews/20261107-astra-progress1179-named-001.ko.md)는 E23/1179 준비행동 뒤 431개의 새 전이를 추가했지만 공식 점수는 5점·착의 0이다. 손 재노출·진입 시도·가림·부분 시야 복구 구간을 분리 보존하되 5→10 성공 구간으로 합성하지 않는다. 마지막 D22 질의는 물리 0이며 행동 응답은 미실행이므로 실제 전이의 행동 라벨로 넣지 않는다. 앞선 E23과 같은 E07 계보로 묶고, 여러 선별 영상도 새 독립 시연으로 세지 않는다. 이후 E25의 실제 파지 변경은 아래처럼 별도 관측 근거로 검토한다.

### E25 실제 재파지 사례

[E25](../reviews/20261107-astra-opposing563-named-001.ko.md)는 release→다른 경계 배치→보정 1회→reclose→국소 follow→차등/시점 검사를 실제로 수행했다. 새 135전이는 해당 중간 기술의 후보 자료로 보존하되 반대 lip 개방·5→10 득점 성공으로 라벨링하지 않는다. 최종 5점은 새 grip의 독립 하중 시험 합격을 뜻하지 않는다. 실제 행동·후행 관측·자율 finish를 분리하고 같은 E07 계보를 독립 학습·검증 출처로 쪼개지 않는다.

### E25→E27 · 기존 파지 변경 뒤 새 작업 접근

E27은 [E25/698의 조건부 후속 출발점](2026-11-07-e25-new-grasp-continuation.ko.md)에서 기존 task-progress 방법을 실제 실행 중이다. E25의 새 국소 지지 근거를 출발점으로 삼되 지지 상태는 `uncertain`이며, 준비행동 698전이와 과거 관측 경계 657·667도 E27에서 새로 관측한다. E25 원본의 후행 영상이나 점수를 현재 actor 입력으로 복사하지 않는다. 이 사례는 재파지와 후속 접근을 실제 환경에서 연결해 검증하는 단계이며, 연결 완료·운반 하중 지지·10점 달성을 미리 승인한 합성 시연이 아니다. 종료 후 준비행동과 새 suffix, 연결부 관측 변화, 공식 결과를 구분해 판단한다. E25와 E27은 모두 E07 공유 계보이므로 독립 시연 두 개로 세거나 학습·평가 양쪽으로 나누지 않는다([재실행의 범위](../guides/continuation-and-branches.ko.md)).
