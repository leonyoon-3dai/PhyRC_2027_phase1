# E28 밑단 후보의 공개 영상 연결 검토

**초기 파지 영역은 몸통 밑단이라는 시각적 근거가 강하다. 목이나 소매 입구를 골랐다는 가설을 현재의 주된 설명으로 올릴 근거는 부족하다.** 다만 앞뒤 밑단 lip을 각각 잡았는지, 같은 면의 양 끝인지, 접힌 여러 겹을 함께 잡았는지는 여전히 미확인이다. 후반의 노란 고리 역시 사용 가능한 몸통 통로라는 확정은 아니다.

E30 실행 중 작성한 개발자 검토를 마감 뒤 공개용으로 정리했다. E30은915전이·5/50·새 득점0·착의0으로 마감했고, E31은 같은 전략의 E28/682 시작점 비교로 선택됐다. 이 검토를 진행 중 actor에 전달하지 않았다. E28·E29의 닫힌 공개 지정 RGB, 공개 wrist depth 패널, 게시된 확정 행동만 사용했다. HDF5·audit·평가 원본·mesh·face ID·숨은 기하·원시 추론은 읽지 않았다. 색이나 actor의 `hem` 표현을 정답으로 삼지 않았다.

공개 E28 확정 행동 D12–D39는 양 gripper close 명령을 유지하며 open/regrasp 명령은 없다. 이는 의도적인 입구 교체가 기록되지 않았다는 보조 근거다. 실제 slip·겹침 변화·파지점의 완전 고정 여부까지 알려주지는 않는다. `obs39`는726경계이므로738 대신 사용하지 않았다. 일반 실행 보고서의 `initial-*`는 episode0경계이며 replay 뒤 첫 actor 관측과 다르다.

## Depth가 추가로 말해 주는 것

obs6·8·12·20·21의 현재 wrist depth 패널을 직접 확인했다. 평면 배치에서 드러난 표면, 들어 올린 뒤의 기울어진 표면과 접힘 형태는 RGB와 양립한다. 그러나 카메라에 보이는 가장 앞 표면의 optical Z만 있으므로, 겹친 천 뒤쪽 lip이나 경계의 연결 관계를 복원할 수 없다. magenta는 invalid, orange는 표시 범위 바깥이며 빈 통로의 증거가 아니다. 현재 패널의 약4.59mm 양자화 간격도 얇은 겹층 분리 판단에 적합한 증거로 취급하지 않는다.

## 후속 비교에 주는 의미

1. **밑단 영역 선택은 유지한다.** 목/cuff를 잘못 골랐다는 전제에서 새 파지를 지시할 이유는 현재 부족하다. 마감 E30의 공개 관측과 선택된 E31의 E28/682 시작점 비교를 함께 평가한다.
2. **264에서 확인할 것은 영역 정체보다 jaw–경계 배치다.** 현재 지정 head뷰의 T형 실루엣과 긴 밑단 띠를 함께 보고, wrist의 두 손가락 사이에 들어갈 경계를 대조한다. 필요하면 허용된 짧은 로봇/손목 자세 조절 뒤 다시 관측한다. 픽셀 색 하나나 depth 값 하나로 lip을 지정하지 않는다.
3. **380에서 구별할 것은 두 경계의 상대 운동이다.** 테이블 또는 유용한 partner anchor 지지를 현재뷰로 확인·복구한 상태에서, 기존 파지를 유지한 작은 한쪽 lift/roll과 다른 wrist/head 시점을 비교한다. 한쪽 노란 경계가 움직일 때 별도의 경계가 남아 간격이 달라지는지, 큰 한 면 전체만 기울어지는지 기록한다. 관측된 두 경계가 다른 층이라는 최종 증명은 아니지만 다음 구조적 조작 선택에 도움이 된다.
4. 같은 면의 접힘만 반복되면 **한쪽 접근 가능한 다른 경계로의 재파지**를 별도 시험으로 검토한다. E25가 이미 수행한 release→다른 경계 배치→close→국소 동행 절차의 재시험임을 명시한다. 하나의 자세 변화에 layer 판정을 강요하거나, 완벽한 빈 배경/입구 가시성을 기다리는 규칙을 만들지 않는다. 몸통 뒤쪽 천이 정상 입구 너머로 보일 수도 있다.

이 검토는 현재 두 파지가 정확히 반대 lip이라는 주장도, 같은 panel이라는 확정도 하지 않는다. **밑단 영역의 큰 연결은 비교적 명확하고, 각 lip/겹층과 실제 손 passage는 불확실하다**는 두 수준을 분리한다. 작은 차등 형상 변화에도 그리퍼·잡은 모서리가 손 가까이 남는다면 자유 구간 정렬 문제도 계속 대안으로 남는다.
