# 옷 가장자리 후보의 독립 시각 검토

**2026-11-06 05:06 UTC 기준.** B1b에 사용한 공개 원본 PNG 3장을 직접 확인했습니다. 관측 2의 두 후보가 같은 왼쪽 조각에 놓인다는 기존 분석에 동의합니다. 지금 확인할 최소 개선은 **여러 가시 성분을 유지하고, 양측을 대표하는지 불명확하면 후보를 보류하는 B1c 비교**입니다. B1c는 별도 구현 중이며 이 문서는 완료 결과를 주장하지 않습니다. 모델 설치·추론·GPU 실행·runtime 변경은 하지 않았습니다.

좌표·원본 SHA·mask 성분 수·depth는 [B1b 결과 JSON](../assets/20261106-b1b-color-depth-roi/result.json)을 참조했습니다. 원본을 수정하거나 새 장면을 합성하지 않았습니다. 이 표는 공개 RGB의 사람이 읽을 수 있는 형상에 대한 검수이며 내부 물체·천 기하를 정답으로 이용하지 않습니다.

**노란 무늬의 끝, 색 mask의 경계, 실제 천의 외곽선, 파지할 수 있는 접힘은 각각 다릅니다.** 파란 천 외곽 중 노랗지 않은 부분도 있고 노란 부분이 안쪽에 보이기도 합니다. 따라서 `colored_band_edge_candidate_unverified`를 그대로 유지하고 `cloth_edge_ground_truth`나 `grasp_point`로 이름을 바꾸지 않는 편이 맞습니다. 유효 depth는 그 픽셀의 표면 거리를 주지만 이 의미 구분을 해결하지 않습니다.
