# E15 준비 · 운반 전 펼침과 파지부터 다시 확인

**사용자의 방향 전환 요청에 따라700경계의 국소 접근 반복에서264경계의 준비 상태 비교로 이동합니다.** 새 `coordinated-opening-first` 전략을 구현하고 전체 CPU208개 검사·독립 검토를 통과했습니다. 실제 펼침·재파지·득점 효과는 아직 미검증입니다.

## 출발점을 바꾸는 이유

닫힌 E07의 지정 공개 RGB에서264경계는 테이블 위 몸판·옆 돌출부·가장자리를 비교하기 상대적으로 쉬운 상태입니다.320경계의 초기 들기에서는 천이 깊게 접히고 로봇 팔이 앞을 가립니다. E13에서도 관절·베이스가 실제로 움직였지만 손목 하우징과 천에 의한 손–테두리 가림이 계속됐습니다. 이는 명령 추종만으로 실패를 설명하기 어렵다는 근거이며, 옷의 정확한 구멍 구조나 특정 파지 오류를 확정한 것은 아닙니다.

E10~E13은 같은 E07 prefix700 이후의 입력·경로 지침을 주로 바꿨습니다. 이번에는 운반 이전에 **그립별 천의 따라 움직임과 여러 시점에서 추적할 수 있는 개구부 형태**를 먼저 확인합니다. 밑단 파지는 여전히 유효한 후보이고 cuff 파지를 강제하지 않습니다. [관련 연구·한계](../research/2026-11-06-stretch4-astra-directions.ko.md)

## 실행할 전략

1. 현재 유효한 양쪽 파지는 보존합니다. 일반적인 open–align–close 준비를 처음부터 반복하지 않습니다. 짧은 확인 동작 뒤 각 그리퍼에서 천이 따라 움직이는지 따로 봅니다.
2. 양쪽 지지가 유용해도 개구부가 읽히지 않으면 짧은 형태 보정을 최대 두 번 지시하고, 매번 새 관측을 받습니다. 어두운 접힘·색 경계만으로 관통 입구를 확정하지 않습니다.
3. 여전히 준비되지 않았거나 한쪽 파지가 명확히 실패했다면, **현재 테이블 지지와 유효한 상대편 파지를 먼저 확인**한 뒤 한쪽 재파지를 한 번 시도할 수 있습니다. 양쪽을 동시에 놓지 않습니다. 테이블 지지가 불명확하면 재파지 조건이 충족된 것으로 처리하지 않습니다.
4. 두 지지점과 몸통 입구 후보가 추적될 때 운반·몸통 입구 진입·소매 출구 순서로 진행합니다. 제한된 복구 후에도 불명확하면 무리한 전진 없이 진단 종료합니다.

횟수 제한은 모델 프롬프트의 지침이며 supervisor가 강제하는 상태기계는 아닙니다. 실제 행동 기록에서 준수 여부를 확인합니다. 전체40결정·1500전이 상한, 단일 계획과 종료 감시는 별도로 유지합니다.

## 비교 조건

- 새 run ID:`20261106-astra-opening264-001`.
- E07의 허용된 행동264전이를 새 에피소드에서 재실행합니다. 정확한 물리 checkpoint 복원이 아닙니다.
- **과거 이미지 추가 없음.** 모델은264경계의 실제 현재5RGB·현재 손목 depth 패널·공개 상태와 수치 depth를 받습니다. 이전 장면의 가장자리 정답·목표 좌표를 공급하지 않습니다.
- Astra/ultra,plan-size1,고정 중립6전이 옵션을 유지합니다. E14는 두 번의 베이스 움직임만 확인했으므로 이 옵션의 과제 효과를 입증한 것은 아닙니다.
- `--profile-step-phases`로 카메라 capture·그 외 observe·그 외 step의 수치 시간을 trusted 기록에 남깁니다. 추가 물리·렌더·관측 호출과 actor 입력 변화는 없습니다. 마지막 항목은 순수 물리 시간이 아닙니다.
- 시작 경계·전략·과거 영상 유무가 함께 바뀌므로 단일 요인 성공률 비교로 해석하지 않습니다. 준비 상태 개선·실제 통과·공식 점수를 구분합니다.

264경계는 이전 픽업5점보다 앞입니다. 새 에피소드는 처음부터 평가하므로 재시작 직후 점수0을 이전5점 상실로 표시하지 않습니다. 기존700전이 분기와 모든 실패 기록은 보존합니다.
