# 공식 데모 참고와 양로봇 협력 전략

[공식 챌린지 페이지](https://emprise.cs.cornell.edu/phyrc/challenge-2027/)의 **[overhead teleop 영상 한 편](https://emprise.cs.cornell.edu/phyrc/assets/c27/media/teleop-overhead.mp4)**을 개발 단계의 전략 참고로 확인했습니다. 사용자 요청은 새 초기 상태에서 두 로봇을 모두 옷 근처로 이동시킨 뒤 함께 파지·들기를 시도하는 것입니다. 아래는 관찰과 후속 전략이며 새 시도의 성공 결과가 아닙니다.

영상은 35.8초·1280×680·30 fps·1,074프레임입니다. 파일 SHA와 조회 시각은 [선별 출처 JSON](../assets/20261106-official-demo/source.json)에 있습니다. 원본 MP4와 추출 프레임은 공개 저장소에 재게시하지 않습니다.

## 영상에서 확인한 순서

아래 시각은 **영상 재생 시각**입니다. 사이트는 8배속으로 소개하지만, 원래 기록의 simulation 시계·편집 정보와 대조하지 않았으므로 실제 제어 시간이나 simulation초로 환산하지 않습니다. 0·2·4·6·8·10·12·14초의 프레임을 직접 확인한 정성적 관찰입니다.

| 영상 시각 | 화면에서 보이는 동작 |
|---|---|
| 00:00~00:04 | 두 로봇이 옷이 놓인 상자의 서로 다른 쪽으로 접근하고 팔을 뻗음 |
| 00:06~00:08 | 양쪽 그리퍼가 옷 가장자리 부근에 모이며 팔·손목 정렬이 진행됨 |
| 00:10~00:12 | 두 측면에서 옷을 잡는 듯한 형상과 가장자리의 들림이 보임. 정확한 파지 성립 시점은 확인하지 않음 |
| 00:14 | 천이 양쪽 그리퍼 사이에 걸린 모습으로 상자에서 벗어나며 운반 단계로 이어짐 |

전체 구간의 요약 프레임에서는 이후 마네킹 쪽 이동과 옷을 올리고 내리는 조정도 확인했습니다. 이 표는 선택 프레임 사이의 모든 움직임을 복원한 것이 아닙니다. 로봇의 정확한 명령·좌표, 내부 파지 anchor, 접촉, 득점 시점이나 최종 점수는 영상으로 추정하지 않았습니다. 화면 좌우 로봇을 새 실행의 robot 0/1과 그대로 대응시키지도 않습니다.

## 새 시도에 적용할 협력 목표

새 actor에는 **사용자가 요청한 일반적인 협력 목표**를 전달합니다. 실제 표적과 행동은 새 실행의 지정 카메라·공개 로봇 상태에서 판단합니다.

1. 두 로봇 모두 옷 근처의 접근 위치를 확보하고, 상대 로봇·상자와의 여유를 현재 공개 관측으로 확인합니다.
2. 한쪽만 먼저 운반하기 전에 두 그리퍼의 정렬과 서로 다른 지지 위치를 확인한 뒤 파지를 시도합니다.
3. 작은 들기에서 천이 각 그리퍼를 따라오는지 관찰하고, 양쪽 지지가 불명확하면 조정·재시도합니다. 닫기 명령만으로 파지 성공을 선언하지 않습니다.
4. 양쪽 지지가 관측되면 함께 들고 운반하는 방향으로 진행합니다. 단계 의도·관측 판단·실제 행동·복구와 별도 공식 평가를 구분해 보존합니다.

고정된 영상 좌표나 재생 시각을 action label로 사용하지 않습니다. 이 목표를 추가한다고 협력 파지나 50점이 보장되는 것은 아니며 실행 결과는 새 run에서 확인합니다.

## 참고 영상과 actor 입력의 경계

[공식 규칙](https://github.com/rirolab/PhyRC_2027_Challenge/blob/main/docs/competition/RULES.md)은 지정 5개 RGB-D 카메라와 공개 로봇 상태 등을 허용하고, 자유 teleop viewport·audit·평가 내부 정보를 학습·추론 입력으로 사용하는 것을 금지합니다. 외부 사전학습·데이터 허용 조항이 공식 환경의 금지 정보를 예외로 만드는 것은 아닙니다.

따라서 영상·추출 프레임·영상 임베딩을 actor 입력이나 학습 자료로 넣지 않습니다. 영상에서 추출한 좌표·궤적·명령도 전달하지 않습니다. 이번 열람은 개발자가 과제의 협력 순서를 이해하기 위한 참고이고, 새 actor의 제어 입력 경계는 기존 지정 5 RGB-D·공개 상태로 유지합니다. **공식 규칙이 이러한 전략 참고에 별도 허가를 명시했다고 주장하지 않습니다.** 출처·용도와 실제 프롬프트를 기록해 해석과 실행을 검토할 수 있게 합니다.
