첫 하강 D13의 공개 `grasp_pose_base` z 변화는 약−32.74/−32.90mm였고 retraction은 약54/85mm였다. 이어진 작은 하강들에서 손·lip 관계는 변했으나 연속 경계 통과를 볼 수 없었다. D18–19 관측 변경의 같은 base-frame z 변화는 약−7mm·−1mm로 작았으며, 단순히 같은 명령만 반복한 것은 아니다. 그러나 두 시점 변경과 새 전후 정렬 후 두 번째 하강도 같은 손끝 가림을 남겼다.

## 마지막 재파지의 실제 범위

D36 뒤 obs37에 robot1 손가락이 벌어지고 몸통이 table 위에 남았다. D37–38 뒤 obs38–39에서 열린 jaw가 다른 노출 front-rim 위치로 옮겨진 것을 확인했다. D39의 실제 행동은 robot1 close8전이이며 짧은 최종 설명도 “들기 전 유지 확인이 필요하다”고 명시했다.

actor 입력 관측은 obs39(1102경계, 마지막 close 직전)까지다. [최종 공개 robot1 wrist RGB](../attempts/20261107-astra-overhead470-named-001/images/final-robot_1_wrist.png)에서는 직전보다 손가락 간격이 줄고 노출된 노란 경계 부근에 닫히는 변화가 보인다. 두 head·overview에서도 몸통은 테이블 위에 남아 있다. **이후 새 파지의 lift/hold 검사는 수행하지 않았다.** 실제 release/reposition/reclose와 성공한 새 지지 구성을 구분한다. 마지막 상태를 양측 지지가 검증된 후속 출발점으로 승격하지 않는다.
