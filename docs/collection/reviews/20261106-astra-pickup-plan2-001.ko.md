# E04: 시각적 완료 판단과 공식 유지 시간의 차이

[시도별 관측·행동·영상](../attempts/20261106-astra-pickup-plan2-001/README.ko.md) · [검수용 boolean·시간 요약](20261106-astra-pickup-plan2-001.json) · [수집 기록](../README.ko.md)

**공식 pickup은 0점입니다. 종료 시 인정된 파지·상승 유지 시간은 2.9초로, 필요한 3.0초보다 0.1초 부족했습니다.** 모델은 마지막 관측에서 pickup 목표를 시각적으로 완료했다고 판단하고 `finish_episode`를 요청했습니다. 정상 파일 종료와 이 모델 판단을 공식 5점 획득으로 기록하지 않습니다.

모델은 공개 관측에서 옷단이 로봇 0을 따라 약 10cm 올라갔고 공개 simulation clock 6.925–9.925초 동안 유지됐다고 설명했습니다. 이 높이와 유지 시작 시각은 **모델의 시각적 추정**입니다.

공식 evaluator가 기록한 169개의 20Hz 표본에서는 다음과 같았습니다. 아래 시각은 reset 이후 **episode clock**이며, 공개 simulation clock의 시작 오프셋 약 1.525초와 구분합니다.

| 조건 | 로봇 0의 true 표본 | 첫 true 표본 | 마지막 true 표본 | 로봇 1의 true 표본 |

공식 scorer는 같은 로봇의 `gripper_holding`과 `gripper_lifted`가 함께 참인 상태의 유지 시간을 셉니다. 마지막 결과의 `pickup_hold_seconds`는 `[2.9, 0.0]`이고 pickup 인정 조건은 3.0초입니다. 따라서 이 종료에서 직접 확인한 부족 조건은 **유지 시간**입니다. 종료 때 로봇 0의 파지·상승 조건 자체는 참이었습니다.

`garment_lifted_clear`는 모든 표본에서 거짓이었으나, 현재 pickup 점수 분기는 이 전역 값 대신 개별 `gripper_lifted`를 사용합니다. 전역 값만 보고 상승 실패로 분류하지 않습니다. 물리 간격을 보수적으로 집계한 공식 표본의 유효 시작은 episode 5.50초, 공개 simulation clock 약 7.025초입니다. 모델이 설명한 시작 6.925초와 약 0.1초 차이가 있습니다.

종료 이후 조건이 계속 유지됐을지는 측정하지 않았습니다. 추가 0.1초를 실행했다면 반드시 5점이었을 것이라고 추정하거나 원본 점수를 보정하지 않습니다. 이번 자료는 시각적 완료 판단·공식 유지 조건·모델의 종료 선택을 분리해 분석하는 부분 성공·미득점 사례로 보존합니다.

토큰 ledger는 13회 호출의 차분 합계와 최종 누계가 일치합니다. 입력 887,823, 캐시 입력 768,768, 출력 6,575, 추론 출력 5,114이며 미확정 호출은 없습니다. 이 시도에서는 실제 다중 구간 응답이 나오지 않았으므로 계획 상한 2의 호출 절감 효과를 검증했다고 표현하지 않습니다.

공개 미디어는 저장 RGB 시작·종료 PNG 10장과 연속 overview 168프레임입니다. 영상은 4배 저속·33.6초이며, 실제 582초의 모델 대기와 호출 시간은 포함하지 않습니다. boolean·시간 검토는 실행 종료 후 신뢰된 검수 영역에서 수행했으며 원시 기하·정점·seed·인증·세션 식별자는 요약에 포함하지 않았습니다. 평가 결과를 actor 입력에 전달하지 않았습니다.
