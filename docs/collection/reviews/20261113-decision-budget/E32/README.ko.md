# E32 판단 예산 분석 — 불완전 수집 근거

**20개 판단의 행동과 마지막 정착까지 완료됐지만 정상 종료 절차가 끝나지 않아 수집은 불완전하다.** 원본의 `complete=false`와 오래된 attempt 상태를 그대로 보존한다.758/758전이를 검사했으나 capture manifest와 두 HDF5의 루트 완료 표식 때문에 전체QC는 실패했다. E32는 정상 학습·재실행 출처로 사용하지 않는다.

기록은 **758 = 380 replay + 256 새 모델 행동 + 120 settle + 명시적 stop1 + 입력EOF 종료 중립1**이다. Client가 수락·기록한 마지막 경계는756이며, D19의 모델744→750과 정착750→756은 모두 남았다. Collector에는 stop756→757, EOF에 따른 중립757→758이 추가됐다. `finish_episode` 요청은 없다. 따라서756이라는 오래된 attempt 값이나758이라는 파일 수 중 하나를 지워 맞추지 않는다.

위 환경 시간은 client의 완료된 적용 행 기준이다. 명시적 stop에는 별도 collector 내부 실행 시간0.692384초가 있지만 측정 범위가 달라 같은 열에 섞지 않았다. EOF 중립의 개별 환경 시간은 없다. 단계명은 의도이며 통과·득점을 인증하지 않는다.

배우 호출은 **21회**, 합계 **1220.871470초**다. 환경 호출 경과646.736852초는 replay324.026041초와 새 모델+정착322.710811초로 나뉜다. 새 판단20개 기준 actor 평균61.04초, 환경 평균16.14초이며, actor/호출은58.14초다. Wrapper·입력 준비·통신·응답을 포함한 경과이며 모델 내부 추론 시간이 아니다.

결정9는 최초 depth-query 응답127.211176초와 동일 관측의 후속 응답65.525487초, 합계192.736663초를 사용했다. Query 자체는 물리를 진행하지 않았다. 이 전체 시간을 query를 사용하지 않았을 경우의 추가 비용이라고 단정하지 않는다. `model_call.wall_s`만 한 번씩 합산해 decision 행의 복사된 시간은 제외했다.

**최종 client 전체 경과·종료 시각·simulator 반환 코드는 미기록이다.** Collector의 별도 wall1915.873023초를 client의 정상 마감 시간으로 대체하지 않는다. Host 실행 도구의 반환143과 `input_closed`는 관측된 사실이며 원인은 미확정이다. 일반 마감과 다른 기록 상태는 [공개 시각·수집 검토](../../20261113-astra-central380-001.ko.md)에도 구분했다.

Root가 확인한 별도 공식 평가는 `valid=true`,5/50·착의0·success=false다. 득점 사건은 replay 경계371의 pickup+5뿐이며 모든 새 판단 묶음과 cleanup의 추가 득점은0이다. **평가 유효성과 capture 전체QC 실패는 동시에 기록한다.** 점수는 배우 입력이나 형상 판정에 사용하지 않았다.

## 추가 판단이 수행한 비교

[담당 공개 관측 검토](../../20261113-astra-central380-001.ko.md)에 따르면 앞15개 판단은 초기 후보 형상 변경·그 관계를 유지한 운반·근접 정렬에 쓰였다. 뒤5개는 pitch, 낮춤, 옆 이동, 후퇴, roll로 실제 관계를 바꿨다.694/706의 넓은 후보 이후732에서 좁은 접힘이 생겼고,744에서 손 시야가 일부 회복됐지만756까지 넓은 후보나 명확한 통과는 확인되지 않았다. 이 표는 그 시각 판정을 새로 확정하거나 단순 시간 증가의 효과로 해석하지 않는다.

E29–E31은 판단 여유를 남기고 actor가 종료했지만, E32는20개 행동을 모두 사용했다. 그러므로 추가 판단이 더 실행될 여지는 있었다. 다만 마지막 관계가 좋아졌다는 보장과 정상 수집 종료가 없으므로 예산을 자동으로40개로 늘리거나 E32 후반을 재실행 출처로 쓰는 근거는 부족하다.

**현재 사용자 중지 지시에 따라 E33은 미실행 계획이며, 클린 서버에서 명시적으로 재개한 뒤에만 아래 비교를 검토한다.** 유효한 E28/632·새 history588/614에서 같은 중앙 전략과20개 새 판단을 유지하는 선택이 타당하다. [출발점 분석](../../../research/2026-11-14-e33-central632-direction.ko.md)은 긴 운반 비용을 줄이면서 첫 손 접근 전 중앙 형상을 조절할 관측 근거를 제시한다. 정상 마감·QC·백업 뒤 유용한 중간 관계가 보존되고20개 예산이 소진됐다면 그 유효한 경계에서 추가20개를 별도 비교할 수 있다. Actor가 먼저 종료했거나 같은 접힘·관계만 반복됐다면 시간만 늘리기보다 방법·출발점을 다시 판단한다. 성공 확률과 추가 득점은 예측하지 않는다.
