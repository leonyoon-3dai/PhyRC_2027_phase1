# E28 결정 예산 분석 기준선

개발자 검토용 로컬 자료이며 미게시 상태다. E29는 현재 승인된 새 결정 20회를 그대로 수행한다. 이 분석은 실행 예산을 바꾸지 않는다.

**E28은 40결정 예산 소진으로 마감됐다.** 738전이 뒤 중립 정리 1전이를 기록해 총 739전이이며 QC 739/739를 통과했다. pickup 5점·착의 0점, `success=false`다.

아래 시간은 닫힌 E28 trace의 `model_call` 및 `applied_segment`만 합산했다. Query 후속 호출은 포함하고 `decision`에 복사된 호출 시간은 중복 계산하지 않았다. 단계는 배우가 기록한 의도이며 확인된 성과가 아니다. 전이 경계 `[시작, 끝)`의 차이가 실제 전이 수다.

공식 득점은 별도 검수 자료에서 대응시켰다. 점수가 발생한 전이의 끝 경계를 포함하는 그룹에 배정했다. 배우의 단계 이름과 득점 항목을 연결해 해석하지 않는다.

전체 45.98분. 결정당 평균 actor **51.36초** + 환경 **16.08초**이며, 전체 경과/40은 **68.97초**다. 모델 호출당 actor 평균은 **44.66초**로 분모가 다르다. 그룹에 배정되지 않은 경과는 61.13초이며, 종료 정리 1전이도 그룹 밖에 둔다. 배우 호출 경과는 Docker·CLI·통신·서비스 대기와 생성 등을 포함하며 내부 추론 시간은 알 수 없다.

마지막 5개 결정은 `first_sleeve`라는 의도로 56전이를 실행했지만 추가 착의 득점은 없었다. 이것만으로 더 많은 결정이 도움이 없었다고 결론낼 수 없으며, 시각적 개선 여부도 이 시간·점수 표만으로 판단하지 않는다.

E29 마감 후에는 replay 738과 새 suffix를 분리하고 새 결정의 동일 지표·공식 추가 득점·공개 관측 검토를 함께 비교한다. 새 actor와 비정확한 행동 replay 때문에 엄밀한 단일 변수 비교가 아니며, 추가 결정의 성공 확률이나 미래 예산을 이 자료만으로 정하지 않는다.
