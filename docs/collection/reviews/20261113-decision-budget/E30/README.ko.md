Query 후속1회를 포함한 actor 호출은20회다. `model_call.wall_s`를 호출당 한 번만 합산했고, 같은 시간을 복사한 decision 행은 더하지 않았다. 환경 시간은 replay·model·settle의 실제 적용 행을 합산했다. 단계명은 의도이며 통과·득점의 증거가 아니다. 각 새 판단 묶음의 추가 공식 득점도0이며, 별도 점수 사건은 actor 입력으로 전달하지 않았다.

전체 경과는 **1850.452945초, 약30.84분**이다. actor 경과1035.999421초, 환경764.021449초이며 환경 중 replay617.940158초와 새 suffix146.081291초를 구분한다. replay는10.30분, 새 suffix의 actor+환경 합계는19.70분, 그 밖의 경과는50.432075초다. 전체 시간을19로 나누면 replay 비용까지 포함되므로 새 결정의 응답 시간으로 사용하지 않는다.

행동 결정18개만 보면 actor 평균 **55.53초**, 환경 평균 **8.12초**다. 종료를 포함한 actor/결정은54.53초, actor/호출은51.80초로 분모가 다르다. actor 경과는 공개 입력 준비·Docker/CLI 시작·요청/응답을 포함하며 모델 내부 추론 시간은 별도로 알 수 없다.

[E29](../E29/README.ko.md)는 같은 E28/738 계보에서10개 행동 결정·96개 새 전이를 기록했고, E30은18개·177개를 기록했다. 두 시도 모두 숫자 예산 전에 종료했고 추가 공식 득점은 없었다. **E30의 더 많은 실제 행동과 변경된 대각선 전략을 결정 수만의 효과로 분리할 수 없다.** 새 actor 문맥과 정확한 천 상태를 보장하지 않는 replay도 차이로 남는다. 호출 시간이 달라졌다는 사실을 서비스·GPU 성능 비교로 해석하지 않는다.

숫자 예산을 더 올리는 것만으로 같은 종료 결정을 막는다는 근거는 없다. 실제로 관측된 낮춤·방향 변경·올림, 정렬과 가시 관계의 변화는 [E30 공개 관측 검토](../../20261113-astra-diagonal738-001.ko.md)에서 별도로 판단한다. 미래 성공 확률은 추정하지 않으며, 다음 비교는 승인된 자동 수집 범위에서 관측 근거에 따라 선택한다.
