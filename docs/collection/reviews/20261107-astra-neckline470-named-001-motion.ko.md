**목 후보 재파지 뒤 실제 로봇 상승과 시점 변경은 있었다. 다만 닫힘과 잔류 운동이 함께 진행됐다.** D10의 robot0 단독 lift는 실측 +26.626mm였고, D19의 양측 lift는 +26.645/+26.218mm였다. D19 robot1에는 새 extension 명령 없이 +10.813mm의 팔 확장도 겹쳤다. D20의 높이·간격 확대와 D21의 시점 보상도 실제 실행됐지만, 이 로봇 수치가 천의 지지·목 입구·통과를 확정하지는 않는다.

## 기준점과 단위

`grasp_pose_base`는 **공개 그리퍼 기준점**이며 실제 천 파지점·접촉 위치의 정답이 아니다. 세계 위치는 공개 base 위치에 정규화한 wxyz 회전으로 그리퍼 기준점을 변환했다. 세계 회전은 base 회전과 grasp 회전의 곱이다. 변위는 두 시점의 차이이며 경로 길이·천 이동량이 아니다.

lift는 공개 `lift_joint` 실측값, arm은 `arm_l1_joint`…`arm_l4_joint`의 합이다. 두 finger 관절은 **rad**, `fingertip_origin_distance`는 공개 손끝 **원점 사이 거리**이며 안쪽 접촉 간격이 아니다. 닫힘 target 0.103rad와의 차이·낮은 속도만으로 천을 잡았거나 놓쳤다고 판정하지 않는다. 아래 판단 D와 관측 obs는0부터 시작하고, obsN은 DN 직전 입력이다.

## 이 수치가 판단하는 범위

D20의 높이·기준점 간격 변화와 D21의 손목 회전은 실측됐으므로 “목 입구를 확인하겠다는 말만 반복하고 로봇은 움직이지 않았다”는 해석은 맞지 않는다. 반면 **새 로봇 자세가 생겼다는 사실과 새 천 개구부 관계가 드러났다는 사실은 다르다.** 이 수치 분석은 천 픽셀·접촉·입구 정체를 측정하지 않았다. 최종 운영 설명은 D21 뒤에도 분리된 입구를 읽지 못했다고 했고 D22에서 낮춘 뒤 D23에 종료했다. 이는 당시 모델의 시각적 판단이며 정답 라벨이 아니다.

다음 비교에서 필요한 것은 새 목표값만 늘리는 것이 아니라 실측 이동, 닫힘·잔류 운동, 국소 천 동행, 입구 관계를 구분한 근거다. 이번 문서는 현재 닫힌 기록을 분석했으며 settle 규칙·목표 한계·후속 실행의 프롬프트를 변경하지 않았다. JSON에는24개 공개 관측 SHA, 선택 공개 HDF5 필드의 범위·dtype·SHA, 적용 행동 대조,10개 구간의 명령 종료/settle 종료 수치와 독립 D21 대조 범위를 남겼다.
