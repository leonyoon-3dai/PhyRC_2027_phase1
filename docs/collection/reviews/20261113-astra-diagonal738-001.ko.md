## 열린 통로와 그리퍼 여유의 불확실성

노란 경계와 손이 화면에서 겹친다는 이유만으로 gripper 충돌이나 입구 통과를 단정하지 않는다. 예를 들어 관측 15의 **현재 robot_1 손목 카메라에서 고른 6개 원본 픽셀**을 비교하면 손 피부 `(157,120)`의 광축 깊이는 약 0.368m, 가까운 jaw `(133,131)`는 0.257m, 손 위 노란 부분 `(151,104)`은 0.443m, 아래 파란 부분 `(167,151)`은 0.577m였다. 보조점은 손목 피부 `(180,121)`와 다른 jaw `(114,131)`였다. 모두 유효한 공개 depth지만 서로 다른 광선 위 값이므로 접촉 거리나 통로 위상을 증명하지 않는다.

이번에는 같은 손과 jaw의 상대 여유를 바꾸는 실제 진전이 있었다. 그래도 **마주 보는 두 입구 층을 제어했는지, 한 겹이나 접힌 여러 겹을 움직였는지**는 해결되지 않았다. 파란 천이 보이는 것만으로 입구가 닫혔다고도, 노란 경계 사이 공간만으로 열린 통로라고도 결론 내리지 않는다. 사용자의 방법 전체가 불가능하다는 결과가 아니라, 이 파지·출발 관계에서 시험한 동작들로 통과를 확인하지 못한 결과다.

## 추가 예산과 다음 비교

추가 행동의 가치는 **분리된 높이·방향 시험, 같은 손의 유지, 중심·그리퍼 여유 변화, 반대쪽 경계 조작의 효과**를 구별한 데 있다. 마지막까지 실제 천 운동은 있었지만 손을 따라 옷이 진행하는 증거는 남지 않았다. 모델이 예산을 한 개 남기고 종료했으므로 같은 상태에 판단 수만 더 주는 근거는 약하다. 전체 실행 시간에는 replay가 포함되고, 모델 호출 경과는 순수 내부 추론 시간이 아니므로 새 조작의 시간 비용과 혼동하지 않는다.

**다음 비교는 E28/682에서 같은 `coordinated-diagonal-entry`·최대 20판단을 유지하고, 새 replay history 632·668을 쓰는 것을 권고한다.** 더 이른 손–입구 관계에서 같은 분리 시험을 시작해 후반 접힘·접근 상태의 영향을 비교한다. 원본이나 관측을 수정하는 방법이 아니다. 총 1,400전이, 검토 기준 10점 등 실행 조건을 유지하며 실제 새 관측에서 지지·대상 손을 다시 확인한다. E30/886과 최종 915는 진단 비교 경계로 보존하되 더 나은 출발점으로 자동 승격하지 않는다.

사용자는 시연→분석→다음 시연의 자율 반복을 승인했다. 각 시도는 마감·QC·고정 백업을 확인한 뒤 분기하고, 같은 계보를 독립 성공 시연으로 세지 않는다. 이후에도 새 손–입구 관계와 실제 진행이 생기는지, 같은 접힘만 반복하는지, 판단·호출·시간과 공식 점수는 어떠한지 따로 검토한다. 이 문서의 권고와 실제 다음 실행·결과는 구분해 기록한다.
