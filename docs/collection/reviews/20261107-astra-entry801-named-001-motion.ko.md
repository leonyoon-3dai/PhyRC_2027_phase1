# E19 · 실제 접근·복귀와 시야 보상 운동

**세 번의 접근은 실제로 실행됐다.** 양측 arm 실측 길이는 각각 약44mm,67mm,55mm 늘었고, 해당 목표 증가도 요청된 공개 속도 scale과 일치했다. 따라서 팔 목표가 제한에 걸려 전진하지 못했다는 설명은 이 구간의 수치와 맞지 않는다. 다만 다음 관측에도 운동이 남았고, 시야 조정이 그리퍼 기준점의 위치를 정확히 유지한 것은 아니다.

[주 검토·공개 영상](20261107-astra-entry801-named-001.ko.md) · [수치와 원본 SHA JSON](20261107-astra-entry801-named-001-motion.json)

실제 실행 소스는 `9aad60138dc5cded2e0e5219fc12395d4c37ff0a`, 시작 시 clean이다. 이 분석은 닫힌 시도의 공개 관측 JSON, `policy.hdf5`의 허용 로봇 상태·행동 필드, 최종 적용 행동만 읽었다. audit·평가·숨은 기하·RGB 분할 라벨을 사용하지 않았다. 코드 변경·모델·GPU·물리 호출·추가 테스트 실행은 없다. 점수로 파지나 실패 원인을 역추론하지 않는다.

## 측정 방법과 기준점

**`grasp_pose_base`는 공개 로봇 그리퍼 기준점이며 실제 천 파지점·접촉 위치의 정답이 아니다.** 세계 위치는 공개 base 위치와 wxyz quaternion으로 그 기준점을 변환했다. quaternion은 정규화했으며 세계 회전은 base 회전과 grasp 기준점 회전의 곱이다. 아래 값은 양 끝의 변위이며 이동 경로 길이·천 이동량이 아니다.

arm 길이는 공개 관절 이름 `arm_l1_joint`…`arm_l4_joint`의 실측 위치 합이다. 공개 `ARM_RATE=1.21m/s`와 실제 명령·전이 수에서 예상 목표 증가를 계산했다. 액터 입력13개를 공개20Hz 상태 경계와 대조해 모두 일치함을 확인했다. 각 행동의 끝과 그 뒤 settle6전이 끝을 따로 읽었고, 후속 액터 관측은 settle 뒤 값이다.

## 세 번의 접근과 복귀

쌍은 robot0 /robot1, 길이는 mm다. “목표 변화”는 양측이 같은 값이며 “세계 기준점 변위”는 방향 없는 크기다. 접근 방향은 양수 arm 확장, 복귀는 음수 arm 확장이다. 모든 행에 정착 중립6전이가 포함된다.

해당 구간의 arm 목표 증가는 `명령×1.21×명령 전이/20`과 최대 **1.41×10⁻⁸m** 차이였다. 목표 증가가 잘렸다는 증거가 없고, 관절과 그리퍼 기준점도 실제로 움직였다. 이것은 모든 관절 제한·다른 시점의 제약이 없었다는 주장이 아니다.

복귀 뒤 그리퍼 세계 위치가 각 접근 전 위치와 정확히 같지는 않았다. D2→3 사이클의 최종 차이는9.829/9.984mm, D5→6은9.042/4.530mm, D10→11은9.323/9.224mm였다. D6에는 의도된 robot0 roll도 있으므로 원래 천 형상이나 관측 조건으로 완전히 복원했다고 볼 수 없다.

각 접근의 실제 arm 증가 중 약54–61%가 명령 종료 뒤의 settle 구간에 발생했다. 복귀 뒤에도 음의 arm 속도가 남았다: D3 약−31.8/−31.9mm/s, D6 −36.6/−42.4mm/s, D11 −29.9/−45.1mm/s. 중립6전이는 위치 목표를 지우거나 수렴을 보장하지 않는다.

D5 중 robot0 lift는 앞선 하강 목표가 유지되는 동안7.107mm 더 낮아졌다. D2/D10 중에는 직전 pitch의 추가 변화 약1.3–1.4도가 함께 나타났다. 따라서 세 접근을 완전히 정착한 자세에서의 순수 arm 병진으로 해석하면 안 된다. **잔류 운동이 있었다는 사실과 실제 접근이 없었다는 해석은 다르다.** 정착이 불완전해도 위 표의 실제44–67mm arm 이동은 관측됐다.

D7 robot0는 lift47.955mm·arm23.570mm 증가와 wrist pitch 약10.934도 변화를 조합했다. 결과적으로 세계 그리퍼 기준점은 작게 이동하면서 회전했다. 기존 검토의 약3.3mm는 **base 좌표에서 본 그리퍼 기준점 변위**이며 플랫폼 base 이동량이나 세계 변위3.774mm와 다르다. robot1은 새 운동 명령이0이었지만 기존 수축 목표가 유지되는 동안 arm이4.880mm 더 수축했다. 그 관측만으로 접촉 여부나 잔류 운동의 모든 원인을 확정하지 않는다.

D8 robot0는 base가101.321mm 이동하고 wrist yaw가약25.126도 바뀌었다. arm도31.430mm 늘었지만 세계 그리퍼 기준점이41.423mm 이동했으므로 **시점 변경과 위치 보상이 함께 있었고 위치 보상은 불완전했다.** 이는 순수 카메라 회전도, 정확히 고정된 천 파지점 주위의 회전도 아니다. 여기서 옷 진입·접촉 좌표를 추론하지 않는다.

세계 위치·회전 수치는 별도 읽기 전용 계산에서도 확인했다. 주 검토의 세 접근 후 가림 반복은 실제 로봇 접근 뒤의 관측과 대응한다. 이 수치가 입구 정체·천 하중 지지·접촉·실패 원인을 확정하지는 않는다. 현재 grasp set의 단순 전진을 중단할 근거와 실제 새로운 가이드 재파지의 효과가 미검증이라는 결론을 함께 유지한다.
